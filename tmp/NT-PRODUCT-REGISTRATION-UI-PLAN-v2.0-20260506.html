P0-5 소매 다운로드 센터 보강 `download_logs`에 expected/success/failed, package_type, source를 추가하고 `/retail/downloads`에 지표/필터/재시도 UI를 붙입니다.
P0-6 다운로드수 API V1 `goods_down_status`와 V2 `download_logs`를 합산해 상품별 다운수, 사용자수, 최근 7일 집계를 반환합니다.

결론

v2.0의 핵심은 다운로드 버튼을 추가하는 수준이 아니라, V1에서 실제 매출 행동과 운영 판단에 쓰이던 다운로드수·사용자수·파일 품질·정산 상태를 V2 소매/도매 화면의 기본 지표로 올리는 것입니다. 소매회원은 판매자료를 바로 받고, 도매회원은 어떤 상품이 실제로 받아지고 팔릴 가능성이 있는지 보며, 운영자는 다운로드와 제작 정산을 한 흐름에서 검증해야 합니다.

다음 구현은 P0-5부터 진행하면 됩니다. 먼저 `/retail/downloads`를 V1 정책 기준으로 보강하고, 같은 집계 API를 `/retail/product/{id}`와 `/wholesale/downloads`가 공유하게 만드는 순서가 가장 안전합니다.
