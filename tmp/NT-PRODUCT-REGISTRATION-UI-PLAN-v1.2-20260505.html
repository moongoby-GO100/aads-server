상품등록은 “도매 상품 DB 입력”이 아니라 뉴톡 판매·촬영·편집숍·직접판매를 연결하는 상품 마스터 생성 업무입니다.

v1.2는 V1 운영중인 관리자 샘플등록/상품수정 페이지를 다시 검수하여, 상품등록의 목적과 역할별 흐름, 페이지별 의존성, V2에 필요한 DB/UI 항목을 재정리한 버전입니다.

신규 파일 기준 시각 2026-05-05 09:44 KST V1 코드 검수: pick.newtalk.kr 관리자 V2 비교: Laravel + Next 관리자 상품상세

핵심 결론

V2 현재 관리자 상품상세는 V1 대체 불가입니다. V2는 상품명, 코드, 설명, 공급가, 소비자가, 상태 중심이고, V1 운영 필수인 촬영/샘플/웹작업/마켓별 상품명/이미지 URL/자동가격/상세스펙/매입처 검증이 빠져 있습니다.

V2 상품등록 UI는 “등록 출처 선택 → 목적별 워크플로우 → 필수 필드 점진 노출 → 촬영/판매/편집숍/직판 의존성 표시” 구조로 바꿔야 합니다.

1. 상품등록 목적 재정의

도매 원칙 등록

정상 원칙은 도매가 상품 원천 정보를 등록하고 뉴톡은 촬영, 가공, 노출, 유통을 지원합니다.

초기 도매 미등록 예상

뉴톡 대행 등록

초기에는 뉴톡관리자가 도매 대신 샘플 입고 후 상품코드, 매입처, 원가, 촬영 요청, 상세정보를 등록합니다.

Phase 1 필수

촬영서비스 연동

샘플입고, 제품촬영, 모델촬영, 웹작업, 이미지컨펌, 샘플반납까지 상품 상태를 따라갑니다.

V1 핵심 흐름

뉴톡 직접판매

뉴톡 자체 판매용 상품은 소비자 가격, 마켓별 상품명, 이미지 URL, 카페24/SNS/편집숍 노출까지 필요합니다.

별도 목적값 필요
