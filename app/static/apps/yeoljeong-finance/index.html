일자 직원 시간 근무 인건비 상태
기본 입사 흐름은 직원 직접 회원가입입니다. 직원은 회원가입 후 가입요청과 입사서류를 등록하고, 관리자는 가입요청 승인, 서류 검수, 계약서 작성과 전자서명을 순서대로 처리합니다. 초대 링크는 전화번호만 알고 있을 때 쓰는 보조 수단입니다.

직원 가입 처리 흐름

회원가입 우선
1. 직원 회원가입 이메일, 연락처, 희망 지점, 주소를 직원이 직접 입력합니다.
2. 가입요청 승인 관리자가 지점과 권한을 확인하고 승인 또는 반려합니다.
3. 입사서류 제출 통장사본, 보건증, 조건부 서류를 직원 본인이 업로드합니다.
4. 계약서 작성 승인 직원 기본값을 계약서에 자동 반영하고 전자서명을 요청합니다.

로그인 필요
업로드일 직원 지점 서류 파일 상태
관리자는 근로계약서를 작성·수정하고 직원에게 서명 링크를 보낼 수 있습니다. 직원은 전달받은 링크로 계약 내용을 확인한 뒤 서명 완료 상태로 처리합니다. 계약서는 승인된 직원 선택 후 4대보험 가입 근로자 또는 3.3% 프리랜서 구분에 맞춰 작성합니다. 근로계약서는 고용노동부 표준근로계약서 서식 모음의 필수 기재축과 2026년 적용 최저임금 고시 시간급 10,320원 기준을 반영합니다. 프리랜서 계약서는 고용노동부 노무제공자 공통 표준계약서 기준으로 업무범위·산출물·검수·정산·해지 기준을 분리하고, 3.3% 원천징수만으로 근로자성이 배제되지 않으므로 지휘·감독, 고정 근무표, 출퇴근 통제, 매장 상시업무 편입 여부를 확인해 근로계약으로 전환해야 합니다. 외국인 직원은 체류자격과 취업 가능 확인 내용을 계약 메모와 입사서류 검수에 함께 남깁니다.
