매장비서 은행 빠른조회·간편조회 PRD

대표와 경리 담당자가 은행 사이트에 매일 접속하지 않아도 등록 계좌의 거래를 자동 수집하고, 실패 시 이유와 다음 행동을 한 화면에서 확인하게 만드는 제품 요구사항입니다.

2026-09-12 KST신한·IBK 1차POST 비동기 요청실데이터 원장

1. 제품 목표와 비목표

구분내용
목표신한 간편조회와 IBK 빠른조회 거래를 국내 PC Agent가 조회하고, 서버가 안전하게 큐잉·적재·집계한다.
목표수동 실행과 매일 자동 실행이 같은 core collector를 사용하며 중복 거래와 중복 실행을 방지한다.
목표로그인 만료·Agent 오프라인·추가 인증을 막다른 오류가 아닌 복구 가능한 상태로 표시한다.
비목표송금·이체·출금 실행, 계좌 비밀번호 화면 노출, LLM의 거래 승인·금액 판단은 범위에 포함하지 않는다.
비목표BankAPI를 필수 외부 의존성으로 채택하지 않는다. 비교 기준과 선택적 비상 대안으로만 본다.

FR-07P1계좌 카드에 현재 상태, 마지막 성공, 신규/중복 건수, 오류, 재시도 동작을 표시한다.샘플 fallback 없이 실제 API 값 또는 빈 상태 표시
FR-08P1자동수집과 수동수집이 동일 queue item/collector 계약을 사용한다.두 진입 경로의 service/account/date payload 동일
FR-09P2NH·KB·우리 어댑터를 동일 interface로 확장한다.은행별 parser/fixture/오류 매핑 계약 테스트

4. API 요구사항

POST /api/v1/yeoljeong-finance/bank-accounts/{account_id}/quick-inquiries
Request: business_id, branch_id, date_from, date_to,
         browser_agent_id(optional), browser_work_key(optional)
Response 202: quick_inquiry.job_id, status, retry_after_seconds

GET /api/v1/yeoljeong-finance/bank-quick-inquiries/{job_id}
Response 200: status, action_required, error_code, message,
              timestamps, result.collected_rows/imported_rows/duplicate_rows

GET /api/v1/yeoljeong-finance/bank-transactions
GET /api/v1/yeoljeong-finance/bank-summary

POST 본문에는 로그인 ID/PW, 전체 계좌번호, PIN, 주민·사업자번호를 받지 않습니다. 자격정보 등록은 기존 별도 권한 API를 유지합니다.

6. 비기능 요구사항

  • 보안: TLS, 관리자 권한, tenant 범위, secret-free queue/response/log, 자격값 평문 영속화 금지.
  • 정합성: 거래 source hash 멱등성, 계좌·사업자·지점 범위 검증, 실행 lease fencing.
  • 가용성: Agent 단절 시 작업 상태 보존, stale lease 복구, 인증 오류와 일시 오류를 분리.
  • 관측성: job ID로 단계·시각·오류·건수 추적. 민감 원문은 trace하지 않음.
  • UX: 모바일에서도 상태/오류/재시도 버튼을 같은 계좌 카드에 배치하고 설정은 별도 경로로 둠.

9. 검수 체크리스트

  1. 비관리자 POST/GET 차단 및 다른 tenant job 404.
  2. 요청·큐·로그·응답에서 password/PIN/account raw 부재.
  3. 같은 지점 복수 Vault 레코드에서 명시 연결 계정 선택.
  4. 동일 계좌 연속 요청 시 브라우저 동시 실행 없음.
  5. Agent 오프라인과 인증 필요 상태에 복구 행동 표시.
  6. 실은행 수집 후 거래목록·은행요약에 같은 건수/금액 반영.
  7. 동일 기간 재수집 시 신규 0, duplicate 증가.
  8. 기존 index.html, 동기 /collect, CSV/XLSX 업로드 회귀 없음.
