4. 업데이트 관리 절차

  1. 앱 수정은 app/static/apps/yeoljeong-finance/index.html을 기준으로 진행합니다.
  2. 기능 분리는 modules/app-config.js에 대상 모듈을 먼저 등록한 뒤, 인증/설정/직원/계약/급여/배달 수집 순서로 외부 모듈 파일로 이동합니다.
  3. 운영 노출 복사본 /root/aads/aads-dashboard/public/apps/yeoljeong-finance/index.html과 /root/aads/aads-dashboard/public/static/apps/yeoljeong-finance/index.html을 동기화합니다.
  4. 문서 수정은 app/static/reports 원본을 먼저 갱신한 뒤 public/reports로 복사합니다.
  5. 검증은 최소 python3 -m py_compile, HTML inline script parser, 공개 URL 마커 확인을 수행합니다.
  6. 작업 내역은 HANDOVER.md에 KST 시각과 함께 남깁니다.
python3 -m py_compile app/api/yeoljeong_finance.py app/services/yeoljeong_finance_service.py
