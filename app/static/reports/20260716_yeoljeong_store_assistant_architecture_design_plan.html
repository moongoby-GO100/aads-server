1. 현재 아키텍처

정적 SPA단일 HTML이 화면 상태, 폼, 렌더링, API 호출을 담당합니다.
FastAPI로그인, 회원가입, 설정, 직원, 입사서류, 계약, 급여 API를 제공합니다.
원장 저장JSON 파일과 일부 DB 설정을 조합해 현재 운영 데이터를 보관합니다.

3. 디자인/모달 기준

컴포넌트현재 기준보완 기준
상단 바매장비서 브랜드, 샘플/가져오기/내보내기/초기화, 인증 상태문서 링크를 고정해 운영자 교육/업데이트 관리 진입점으로 사용
탭대시보드부터 설정까지 업무별 탭직원 권한에서는 본인 업무만 노출하고, 관리자 권한은 전체 업무 노출
모달전화 초대, 계약 링크, 확인 팝업 등 단일 레이어 중심삭제/승인/서명요청 등 irreversible action은 사유와 대상명을 명시
로그인 게이트직원 회원가입을 기본 진입으로 두고 운영자 로그인은 별도 탭 제공#auth-invite는 초대 수락이 아니라 직원 이메일 인증 회원가입 화면으로 사용하고 초대 링크는 보조 토큰 입력값으로만 처리
직원 온보딩 화면회원가입 후 #auth-employee-home, #auth-employee-profile, #auth-employee-documents 순서로 진행#auth-invite는 직원 간편 가입, #auth-employee-home은 직원 첫 화면, #auth-employee-profile은 기본정보, #auth-employee-documents는 입사서류 탭으로 연결한다. 직원이 직접 기본정보와 서류를 입력하고, 관리자는 검토·수정·계약작성만 처리
직원관리/급여관리 분리직원 원장·계약과 급여 계산·지급을 별도 메뉴로 분리#employees는 직원 가입, 서류, 계약조건, 작성본 미리보기, 상황별 양식함 중심으로 유지하고 #payroll은 급여 마감, 근태·수당 예외, 공제, 명세서, 승인, 지급예약을 전담
연동 설정 드로어판매사이트, 은행, 매입처, 홈택스별 필수 입력값을 다르게 노출비밀번호·인증서·토큰은 Vault 암호화, 화면 재표시는 마스킹, 만료/실패는 알림 큐로 처리
계약 프리뷰A4 문서처럼 보이는 프리뷰와 인쇄/PDF 버튼모바일과 데스크톱 모두 PDF 다운로드와 인쇄 전 중앙 미리보기 모달을 먼저 띄워 문서내용, 민감정보 마스킹, 권한, 최신 버전을 확인하게 한다.
상태 배지대기/승인/작성필요/요청됨 등 텍스트 배지색상만으로 구분하지 않고 상태 문구를 항상 함께 표시

4. 현재 방식이 최선인지 판정

현재 판정 지금 개발된 방식은 빠른 운영 검증과 CEO 피드백 반영에는 좋은 선택입니다. 단일 정적 SPA라 배포/수정 속도가 빠르고, FastAPI API를 붙여 실제 직원·계약·급여 흐름까지 검증할 수 있습니다.

다만 장기 최선안은 아닙니다. 기능이 이미 직원 승인, 입사서류, 계약서, 급여, 배달앱 계정, 사업자 설정까지 확장되어 단일 HTML의 변경 위험이 커졌습니다. 실사용자가 늘기 전에는 저장소를 PostgreSQL 중심으로 전환하고, 프론트는 컴포넌트 기반으로 분리하는 것이 맞습니다.

5. 최신 CEO 지시 반영 설계

5-1. 직원 가입 흐름

단계권장 UX디자인 기준예외 처리
1간편 회원가입FB 로그인 화면 기본값을 직원 회원가입으로 두고 이메일 아이디, 비밀번호, 소속, 휴대폰번호 4개만 입력초대 링크는 기본값이 아니라 관리자가 보낸 경우의 보조 확인값으로만 유지
2이메일 인증·직원 홈 진입가입 CTA 이후 인증 메일을 발송하고 인증 완료 시 #auth-employee-home에서 기본정보/서류등록 할 일을 표시중복 전화번호·이메일은 병합 후보로 표시
3기본정보 입력·선택#auth-employee-profile에서 이름, 생년월일, 주소, 긴급연락처, 급여계좌, 지점, 직무, 입사유형, 근무 가능 요일/시간을 직원이 직접 입력입력값은 관리자 수정 가능 상태로 직원 원장과 계약서 초안에 반영
4입사서류 등록#auth-employee-documents에서 통장사본, 보건증, 신분 확인, 주민등록등본, 자격증 선택 등 필요한 서류만 파일 업로드/OCR/마스킹 검토민감정보 원본 보관 금지, 필요한 경우 재제출 요청
5관리자 계약 작성승인 직원 기본값을 계약서에 자동 반영하고 시급, 근무지, 계약기간, 4대보험/3.3% 조건 입력외국인/미성년/프리랜서는 추가 체크리스트 표시
6계약서 작성본 미리보기#employees에서 A4형 계약서 프리뷰, PDF/인쇄 전 중앙 모달, 전자서명 요청 버튼을 제공작성 전에는 누락 필드 경고, 작성 후에는 문서보관함 분류와 버전 이력 표시. PDF 다운로드와 인쇄는 모달에서 최종 확인 후 실행한다.
7급여관리 별도 메뉴#payroll에서 근태 마감, 연장/야간/휴일수당, 4대보험/3.3% 공제, 명세서 미리보기, 은행 지급예약을 분리 확인급여 확정 전에는 월별 잠금 전 상태로 표시하고 대표 승인 후 지급예약으로 이동. 직원관리 화면에는 급여 계산을 노출하지 않고 급여관리 이동 CTA만 둔다.
