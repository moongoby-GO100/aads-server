4. 실행 시퀀스

[학습 1회차]
지시 → 레시피 없음 → LLM 탐색 실행(브리지 도구 호출) → 성공
     → 호출 순서·선택자·검증조건을 YAML로 직렬화 → work_recipes v1 저장

[재생 2회차 이후]
지시 → 도메인+의도로 레시피 매칭 → Risk Gate 사전 스캔
     → READ/WRITE_INTERNAL 단계는 즉시 실행 (LLM 호출 0)
     → WRITE_EXTERNAL/IRREVERSIBLE 도달 시 실행 중단 + 승인 카드 발행
     → 승인 수신 후 재개 → 검증조건 확인 → recipe_runs.success

[실패 복구]
단계 실패(선택자 없음/타임아웃) → 스냅샷 1장 + 실패 단계만 LLM 전달
     → 대체 경로 성공 시 해당 단계만 교체 → version+1 저장 (전체 재학습 금지)

9. v2.0 논리 아키텍처

사용자 채팅 / 오비스 실행 화면
          │
          ▼
Ohvis Orchestrator ─ Intent Planner ─ Preflight Resolver
          │                    ├─ NEEDS_ACCOUNT → Credential Broker → Vault
          │                    ├─ NEEDS_RECIPE  → Recipe Registry / Draft
          │                    └─ NEEDS_APPROVAL→ Policy + Approval Gate
          ▼
Recipe Player ─────────────── Browser Bridge / PC Agent
          │                              │
          ├─ Evidence / Append-only Audit┤
          └─ Conversation Resume / Report┘
계층책임신뢰 경계
Ohvis Orchestrator목표 분해, 상태 전이, 진행·완료 보고모델 출력은 계획 후보일 뿐 실행 권한이 아님
Intent Planner사이트·출력·위험등급·필수값 계획페이지 텍스트를 시스템 지시로 해석 금지
Preflight Resolver계정·레시피·입력·승인 blocker 판정질문 중복 방지 키 유지
Credential Broker/Vault안전 등록, scope, 로그인 세션비밀은 Vault 밖으로 반환하지 않음
Recipe Registry/Player버전 레시피 등록·결정적 재생미승인 draft 실행 금지
Policy/Approval GateA/B/C 승인과 4단계 위험 정책scope·preview hash·만료 확인
Browser Bridge/PC Agent웹/로컬 도구 실행도구·도메인 allowlist
Evidence/Audit단계 결과·스크린샷·승인 1:1 기록append-only, 중첩 시크릿 마스킹
Conversation Resumecheckpoint·resume·idempotency완료된 외부행위 재실행 금지

10. 실행 시퀀스

1. message → intent plan → PREFLIGHT
2. account/recipe/input/policy 확인
3. blocker 없음: READ 자동 실행
4. blocker 있음: 상태·checkpoint 저장 → 질문/승인 카드 1개
5. 답변/승인: scope와 hash 재검증 → resume_token 소비
6. Browser Bridge 실행 → 단계별 evidence/audit append
7. VERIFYING → 결과·변경·미완료·후속 제안 보고
