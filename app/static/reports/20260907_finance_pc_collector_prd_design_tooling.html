LangGraph와 LangSmith 기반 실행 하네스/LLMOps를 붙인 Windows 설치형 금융 수집 에이전트 구축안입니다. 1차 목표는 은행 빠른계좌조회 로그인/조회, 거래내역 파싱, 엑셀 다운로드, 서버 업로드, DB화, 실시간 감시와 주기 업데이트입니다. 신한은행은 비밀번호 5회 오류 차단 해제 전까지 보류하고, IBK기업은행 빠른조회서비스를 우선 구축 대상으로 전환합니다.

문서 버전: v1.2 최종 갱신: 2026-09-08 08:35 KST 작성 범위: 1. 설계/PRD 2. 화면 목업 3. Tool 셋업 + 4단계 IBK 우선 전환 현황 구축 상태: 통합 Finance Collector EXE 빌드 타깃 구현, IBK 실수집은 자격값 대기 대상 PC: 은행 전용 Windows PC Agent 레인 IBK URL: 기업은행 빠른조회서비스 직접 진입

1. CEO 승인 요청 결론

권장안은 "Windows 전용 Collector + 서버 관제/저장 + LangGraph 상태머신 + LangSmith LLMOps" 구조입니다. 서버 headless 브라우저로 은행을 뚫는 방식이 아니라, 보안프로그램이 설치된 Windows PC에서 전용 Collector가 실제 브라우저를 조작하고, AADS 서버는 큐, 저장, 감사로그, 재시도 정책, LLMOps 진단을 담당합니다.
