1. Executive Summary

핵심 결론: 진아실장의 커스텀 Python 오케스트레이션(4,698줄 하네스 + 254개 도구)을 Hermes Gateway(프론트) + LangGraph(오케스트레이션) + LangChain(도구통합) + LangSmith(모니터링) 스택으로 전환하면, 멀티테넌트 공용화 + LLMOps 관측성 + 멀티채널 접속을 동시에 달성할 수 있습니다. 기존 148개 도구 중 120+개는 LangChain Tool로 래핑하여 그대로 재사용 가능합니다.
🏗️

2.4 공용화 시 문제점

🔴

인증 없음

전역 비밀번호 1개(BISEO_APP_PW). 사용자 구분 불가, RBAC 없음, 세션 관리 없음.

🔴

테넌트 격리 없음

금고에 tenant_id 없음. 장부 파일에 회사 구분 없음. 야간작업 하드코딩.

🔴

관측성 없음

LLM 호출 비용·지연·실패를 _모델호출장부.jsonl에 수동 기록. 대시보드 없음, 알림 없음.

🟡

단일 채널

PWA 웹앱 1개 + ntfy 단방향 알림. 모바일 네이티브 앱 없음, 메신저 연동 없음.

3. 기술 스택 선정 근거

🔮

Hermes Agent (Nous Research)

역할: 멀티채널 메시징 게이트웨이 + 스킬 시스템

MIT 라이선스, 셀프호스팅, 12+ 메신저 통합 (Telegram, Discord, Slack, WhatsApp, ntfy 등). 경험 기반 자기 개선 학습 루프. 세션 간 영속 메모리.

Gateway Skills Memory MIT License Self-hosted
🕸️

LangGraph

역할: 에이전트 오케스트레이션 (하네스 대체)

StateGraph 기반 멀티에이전트 워크플로우. 조건부 라우팅, 체크포인팅(자동 복구), 순환 그래프 지원. AADS에서 이미 8-agent 그래프 운영 중 (실증 완료).

StateGraph Checkpoint Conditional Routing AADS 실증
🔗

LangChain

역할: 도구 통합 레이어 (148개 도구 표준화)

StructuredTool 래핑, 멀티 LLM 프로바이더 추상화, Document Loader, Vector Store (규칙/지식 검색). 기존 Python 함수를 @tool 데코레이터만으로 LangGraph 노드에 연결.

StructuredTool Multi-Provider Document Loader
📊

LangSmith

역할: LLMOps 관측성 플랫폼 (모델호출장부 대체)

모든 LLM 호출 자동 트레이싱. 테넌트별 비용 추적, 지연 시간 모니터링, 품질 평가 데이터셋 구축, 실패 디버깅. 프로덕션 대시보드.

3.2 왜 Hermes Gateway인가?

현행: 커스텀 채팅서버

  • PWA 웹앱 1개만 지원
  • ntfy 단방향 알림 (하드코딩)
  • 인증: 전역 비밀번호 1개
  • 채팅 이력: 파일 기반
  • 새 채널 추가 시 전면 개발 필요

TO-BE: Hermes Gateway

  • 12+ 메신저 동시 지원 (설정만으로)
  • 양방향 대화 (명령→결과→후속)
  • 플랫폼별 네이티브 인증
  • 영속 메모리 (세션 간 학습)
  • 스킬 자동 생성 (반복 패턴 학습)
  • ntfy 네이티브 지원 (기존 호환)

4.3 멀티테넌트 격리 모델

┌─ 테넌트 격리 계층 ──────────────────────────────────────────────────┐
│                                                                      │
│  Layer 1: Hermes Gateway                                             │
│  ├─ 채널별 tenant_id 매핑 (Telegram group → 라일론)                   │
│  └─ 메시지에 tenant_id 자동 태깅                                      │
│                                                                      │
│  Layer 2: LangGraph State                                            │
│  ├─ AADSAccountingState.tenant_id (모든 노드에서 전파)                │
│  └─ 테넌트별 별도 thread_id (체크포인트 격리)                          │
│                                                                      │
│  Layer 3: LangChain Tools                                            │
│  ├─ 위하고 워커: --방 {tenant_id} (기존 room 패턴 재사용)             │
│  ├─ 금고: tenant_id 필터링 (HKDF 키 파생)                            │
│  └─ 장부: tenant_id 컬럼 WHERE 절 자동 주입                          │
│                                                                      │
│  Layer 4: PostgreSQL                                                 │
│  ├─ 모든 테이블에 tenant_id NOT NULL                                  │
│  ├─ RLS (Row Level Security) 정책                                    │
│  └─ 테넌트별 스키마 분리 (선택적)                                     │
│                                                                      │

6.2 LangGraph State 정의

graph/state.py 
"""공용 회계프로그램 — LangGraph State 정의"""
from typing import TypedDict, Annotated, Optional, Literal
import operator
from langgraph.graph import add_messages


def _last(a, b):
    return b


def _merge_cost(a: dict, b: dict) -> dict:
    result = dict(a)
    for k, v in b.items():
        if k in result and isinstance(v, (int, float)):
            result[k] = result[k] + v
        else:
            result[k] = v
    return result


class AccountingState(TypedDict):
    # ── 테넌트 식별 ──
    tenant_id: Annotated[str, _last]
    company_name: Annotated[str, _last]

    # ── 메시지 ──
    messages: Annotated[list, add_messages]

    # ── 작업 ──
    department: Annotated[str, _last]  # 재무, 인사, 투자, 교육
    task_type: Annotated[Optional[str], _last]
    task_description: Annotated[str, _last]

    # ── 에이전트 라우팅 ──
    current_agent: Annotated[Optional[str], _last]  # 진아, 진식, 서린, 부서장
    agent_model: Annotated[Optional[str], _last]

    # ── 도구 실행 결과 ──
    tool_results: Annotated[list[dict], operator.add]
    wehago_actions: Annotated[list[dict], operator.add]

    # ── 검증 ──
    verification_result: Annotated[Optional[dict], _last]
    verification_count: Annotated[int, _last]

    # ── 비용 추적 ──
    llm_calls_count: Annotated[int, _last]
    total_cost_usd: Annotated[float, _last]
    cost_by_model: Annotated[dict, _merge_cost]

    # ── 제어 ──
    status: Annotated[Literal[
        "접수", "배정", "실행중", "검증중",
        "완료", "실패", "대기"
    ], _last]
    error_log: Annotated[list[str], operator.add]

6.3 LangGraph Builder (하네스 대체)

graph/builder.py 
"""공용 회계프로그램 — LangGraph StateGraph 빌드
현행 _하네스.py (4,698줄) → StateGraph (~200줄)로 전환
"""
from langgraph.graph import StateGraph, START, END
from graph.state import AccountingState
from graph.nodes.intake import intake_node
from graph.nodes.department_router import department_router_node
from graph.nodes.executor import executor_node
from graph.nodes.verifier import verifier_node
from graph.nodes.reporter import reporter_node


def route_after_intake(state: AccountingState) -> str:
    if state["llm_calls_count"] >= 15:
        return "__end__"  # CEO 규칙: 15회/task
    return "department_router"


def route_after_execution(state: AccountingState) -> str:
    if state["status"] == "실패":
        return "reporter"
    if state["llm_calls_count"] >= 15:
        return "reporter"
    return "verifier"


def route_after_verification(state: AccountingState) -> str:
    v = state.get("verification_result") or {}
    if v.get("verdict") == "pass":
        return "reporter"
    if state["verification_count"] >= 3:
        return "reporter"  # 최대 3회 재시도
    return "executor"  # 재작업


def build_accounting_graph() -> StateGraph:
    """
    접수 → 부서배정 → 실행 → 검증 → 보고
                       ↑←──(fail, max 3)──┘
    """
    builder = StateGraph(AccountingState)

    # 노드 등록
    builder.add_node("intake", intake_node)
    builder.add_node("department_router", department_router_node)
    builder.add_node("executor", executor_node)
    builder.add_node("verifier", verifier_node)
    builder.add_node("reporter", reporter_node)

    # 엣지
    builder.add_edge(START, "intake")
    builder.add_conditional_edges("intake", route_after_intake, {
        "department_router": "department_router",
        "__end__": END,
    })
    builder.add_edge("department_router", "executor")
    builder.add_conditional_edges("executor", route_after_execution, {
        "verifier": "verifier",
        "reporter": "reporter",
    })
    builder.add_conditional_edges("verifier", route_after_verification, {
        "executor": "executor",
        "reporter": "reporter",
    })
    builder.add_edge("reporter", END)

    return builder


async def compile_graph(checkpointer=None):
    builder = build_accounting_graph()
    return builder.compile(checkpointer=checkpointer)

from langchain_core.tools import tool
from pydantic import BaseModel, Field
import subprocess
import json


class WehagoInput(BaseModel):
    action: str = Field(description="수행할 작업: 전표입력, 전표조회, 인쇄, 메뉴이동")
    tenant_id: str = Field(description="회사 식별자 (방 이름)")
    data: dict = Field(default_factory=dict, description="작업 데이터")


@tool(args_schema=WehagoInput)
def wehago_erp(action: str, tenant_id: str, data: dict) -> str:
    """위하고 ERP 자동화 실행. 전표입력, 조회, 인쇄 등 수행."""
    cmd = [
        "python3", "도구/위하고_워커.py",
        "--방", tenant_id,
        "--작업", action,
        "--데이터", json.dumps(data, ensure_ascii=False),
    ]
    result = subprocess.run(cmd, capture_output=True, text=True, timeout=300)
    return result.stdout or result.stderr

"""LangSmith 자동 트레이싱 — 모든 LLM 호출에 tenant_id 태깅"""
import os
from langsmith import Client
from langsmith.run_helpers import traceable

# 환경변수 설정 (서버 시작 시)
os.environ["LANGCHAIN_TRACING_V2"] = "true"
os.environ["LANGCHAIN_API_KEY"] = os.getenv("LANGSMITH_API_KEY", "")
os.environ["LANGCHAIN_PROJECT"] = "acct-platform"

client = Client()


@traceable(run_type="chain", name="accounting_task")
async def run_accounting_task(tenant_id: str, task: str, department: str):
    """회계 작업 실행 — LangSmith에 자동 트레이싱"""
    from graph.builder import compile_graph
    from langgraph.checkpoint.postgres import PostgresSaver

    checkpointer = PostgresSaver.from_conn_string(os.getenv("DATABASE_URL"))
    graph = await compile_graph(checkpointer=checkpointer)

    config = {
        "configurable": {
            "thread_id": f"{tenant_id}_{department}",
        },
        "metadata": {
            "tenant_id": tenant_id,
            "department": department,
        },
    }

    initial_state = {
        "tenant_id": tenant_id,
        "department": department,
        "task_description": task,
        "messages": [{"role": "user", "content": task}],
        "status": "접수",
        "llm_calls_count": 0,
        "total_cost_usd": 0.0,
        "cost_by_model": {},
        "tool_results": [],
        "wehago_actions": [],
        "error_log": [],
        "verification_count": 0,
    }

    result = await graph.ainvoke(initial_state, config=config)
    return result

7.2 MCP (Model Context Protocol) 서버 구성

기존 148개 도구를 MCP 서버로 노출하면, Hermes Agent와 LangGraph 모두에서 표준 프로토콜로 호출 가능합니다.

tools/mcp_server.py 
"""MCP 서버 — 진아실장 도구를 MCP 프로토콜로 노출"""
from mcp.server import Server
from mcp.types import Tool, TextContent
import json

app = Server("acct-tools")

# 기존 도구를 MCP Tool로 등록
TOOL_REGISTRY = {
    "wehago_erp": {"module": "도구/위하고_워커.py", "description": "위하고 ERP 자동화"},
    "vault": {"module": "도구/_금고.py", "description": "자격증명 관리"},
    "card_closing": {"module": "도구/카드마감.py", "description": "카드 매입 마감"},
    "cross_verify": {"module": "도구/교차검증.py", "description": "다중 LLM 교차검증"},
    "ocr": {"module": "도구/_ocr.py", "description": "문서 OCR"},
    # ... 148개 전체 등록
}

@app.list_tools()
async def list_tools():
    return [
        Tool(name=name, description=info["description"],
             inputSchema={"type": "object", "properties": {
                 "tenant_id": {"type": "string"},
                 "action": {"type": "string"},
                 "params": {"type": "object"},
             }})
        for name, info in TOOL_REGISTRY.items()
    ]

@app.call_tool()
async def call_tool(name: str, arguments: dict):
    info = TOOL_REGISTRY[name]
    # subprocess로 기존 도구 실행 (격리)
    import subprocess
    result = subprocess.run(
        ["python3", info["module"], json.dumps(arguments)],
        capture_output=True, text=True, timeout=300,
    )
    return [TextContent(type="text", text=result.stdout)]

8. 데이터 모델 (DB 스키마)

db/models.py (SQLAlchemy) 
"""PostgreSQL 스키마 — 진아실장 JSONL → 정규화 DB"""
from sqlalchemy import (
    Column, String, Integer, Float, Boolean, DateTime,
    ForeignKey, JSON, Text, Index, func
)
from sqlalchemy.orm import DeclarativeBase, relationship
import uuid


class Base(DeclarativeBase):
    pass


class Tenant(Base):
    __tablename__ = "tenants"
    id = Column(String, primary_key=True, default=lambda: str(uuid.uuid4())[:8])
    name = Column(String, nullable=False)            # 라일론, 티디에이치컴퍼니
    alias = Column(String)                             # 바이로그인→라일론
    wehago_room = Column(String)                       # 위하고 워커 --방 값
    is_active = Column(Boolean, default=True)
    created_at = Column(DateTime, server_default=func.now())


class TenantUser(Base):
    __tablename__ = "tenant_users"
    id = Column(String, primary_key=True)
    tenant_id = Column(String, ForeignKey("tenants.id"), nullable=False)
    username = Column(String, nullable=False)
    role = Column(String, default="user")           # admin, manager, user
    channel = Column(String)                          # telegram, web, slack
    channel_id = Column(String)                       # 메신저 사용자 ID
    __table_args__ = (Index("ix_tu_tenant", "tenant_id"),)


class Credential(Base):
    """기존 금고/금고.jsonl → DB"""
    __tablename__ = "credentials"
    id = Column(Integer, primary_key=True, autoincrement=True)
    tenant_id = Column(String, ForeignKey("tenants.id"), nullable=False)
    site_name = Column(String, nullable=False)
    encrypted_data = Column(Text, nullable=False)    # AES-256-GCM (기존 방식 유지)
    key_derivation = Column(String, default="hkdf") # 테넌트별 키 파생
    is_active = Column(Boolean, default=True)
    __table_args__ = (Index("ix_cred_tenant", "tenant_id"),)


class Directive(Base):
    """기존 기억/지시대장.jsonl → DB"""
    __tablename__ = "directives"
    id = Column(Integer, primary_key=True)
    tenant_id = Column(String, ForeignKey("tenants.id"), nullable=False)
    department = Column(String)                       # 재무, 인사, 투자, 교육
    description = Column(Text, nullable=False)
    assigned_agent = Column(String)                   # 진아, 진식, 서린
    status = Column(String, default="pending")
    priority = Column(Integer, default=0)
    created_at = Column(DateTime, server_default=func.now())
    completed_at = Column(DateTime)
    result = Column(JSON)
    __table_args__ = (Index("ix_dir_tenant_dept", "tenant_id", "department"),)


class ModelCallLog(Base):
    """기존 기억/_모델호출장부.jsonl → DB (LangSmith 보조)"""
    __tablename__ = "model_call_logs"
    id = Column(Integer, primary_key=True)
    tenant_id = Column(String, ForeignKey("tenants.id"), nullable=False)
    model = Column(String, nullable=False)
    role = Column(String)                             # 진아, 부서장, 검증
    input_tokens = Column(Integer)
    output_tokens = Column(Integer)
    cost_usd = Column(Float)
    latency_ms = Column(Integer)
    langsmith_run_id = Column(String)                 # LangSmith trace 연결
    created_at = Column(DateTime, server_default=func.now())
    __table_args__ = (Index("ix_mcl_tenant_date", "tenant_id", "created_at"),)


class AuditLog(Base):
    """기존 금고/꺼낸기록.jsonl + 제재장부.jsonl → DB"""
    __tablename__ = "audit_logs"
    id = Column(Integer, primary_key=True)
    tenant_id = Column(String, ForeignKey("tenants.id"), nullable=False)
    action = Column(String, nullable=False)         # credential_access, sanction, ...
    actor = Column(String)                            # 진아, 진식, user:xxx
    target = Column(String)
    details = Column(JSON)
    created_at = Column(DateTime, server_default=func.now())
    __table_args__ = (Index("ix_audit_tenant", "tenant_id"),)


class NightTask(Base):
    """기존 _야간작업.py 하드코딩 → DB 스케줄"""
    __tablename__ = "night_tasks"
    id = Column(Integer, primary_key=True)
    tenant_id = Column(String, ForeignKey("tenants.id"), nullable=False)
    task_name = Column(String, nullable=False)
    schedule_cron = Column(String, default="0 3 * * *")
    task_config = Column(JSON)
    is_active = Column(Boolean, default=True)
    last_run = Column(DateTime)
    __table_args__ = (Index("ix_nt_tenant", "tenant_id"),)

R-003 PostgreSQL 마이그레이션 시 기존 JSONL 데이터 손실 높음 낮음 마이그레이션 전 JSONL 전체 백업 + 검증 스크립트 (건수 대조, 해시 비교). 기존 JSONL 파일 삭제하지 않고 1개월 보존

R-005 전환 기간 중 진아실장 서비스 중단 높음 낮음 기존 systemd 서비스 전혀 건드리지 않고 별도 프로세스로 신규 시스템 구동. 전환 완료 후 트래픽 스위칭
R-006 무료 AI 12종의 LangChain 호환성 미검증 중 중 LangChain ChatOpenAI(base_url=...) 호환 형식인 Groq/Mistral/Together는 즉시 사용 가능. 비호환 프로바이더는 커스텀 ChatModel 작성 (1~2시간/건)
