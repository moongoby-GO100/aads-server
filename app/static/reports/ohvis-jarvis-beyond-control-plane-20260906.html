5. Control Loop: 계획→실행→검증→학습 NEW — 핵심

12축은 "무엇을 제어할 것인가"를 정의한다. Control Loop는 "12축이 어떻게 순환하는가"를 정의한다. CEO의 "AI가 스스로 연구개선을 잘하게 할 수 있는 방법"이라는 질문의 답이 바로 이 루프다.

단계입력처리출력관련 축검증 기준

③ 검증 (Verify) 실행 결과, acceptance criteria, 테스트 결과 출력 validator → 테스트 실행 → health check → 완료 계약 확인 → CEO 보고 검증 보고서, 승인 요청 카드 ④품질 ⑫보안 ⑩지식 validator 통과율 95%+, 검증 없는 완료 보고 0건
④ 학습 (Learn) 검증 결과, CEO 피드백, 품질 점수, 비용 실적 성공 패턴 skill화 → 실패 원인 Reflexion → 정책 승격 → eval replay skill library, error_pattern, prompt_assets 승격 ⑤메타인지 ⑩지식 ④품질 동일 실패 재발률 <10%, skill 재사용률 >30%
