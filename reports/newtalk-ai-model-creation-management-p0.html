설계 개념

AI 모델을 "한 번 만드는 것"은 시작일 뿐입니다. 실제 운영에서는 같은 모델이 상황에 따라 헤어, 메이크업, 표정, 포즈, 계절 의상을 바꿔야 합니다. 이 기획서의 핵심은 모델의 정체성(얼굴·체형·톤)은 고정하면서 스타일 레이어만 교체할 수 있는 구조를 만드는 것입니다.

3계층 아키텍처

Base Identity (불변) — 얼굴 골격, 체형, 피부톤, 고유 분위기 → 한 번 확정하면 변경 불가
Style Layer (교체 가능) — 헤어, 메이크업, 액세서리, 네일, 표정 → 상황별 자유 교체
Scene Layer (1회성) — 포즈, 배경, 조명, 의상 → 촬영(생성)마다 새로 설정

🧬 Base Identity

절대 변경 불가. 모델의 DNA 같은 것입니다.

  • 얼굴 골격 (정면/3/4/측면 reference 20장+)
  • 체형 (키, 어깨 너비, 체형 타입)
  • 피부톤 (CIE Lab 기준값)
  • 눈/코/입 비율, 광대, 턱선
  • 고유 분위기 (밝은/차분한/도시적 등)

💄 Style Layer

자유 교체 가능. 프리셋으로 저장/재사용합니다.

  • 헤어스타일 (컷, 길이, 컬러, 스타일링)
  • 메이크업 (베이스, 아이, 립, 블러셔)
  • 액세서리 (귀걸이, 목걸이, 안경, 모자)
  • 네일 (색상, 길이, 디자인)
  • 표정 (미소, 무표정, 웃음, 시선 방향)

📸 Scene Layer

1회성 설정. 촬영(생성)마다 새로 정합니다.

  • 포즈 (전신, 반신, 앉기, 걷기 등)
  • 배경 (스튜디오, 야외, 카페, 오피스)
  • 조명 (자연광, 스튜디오, 야간)
  • 의상 (상품 착용 — 코디 단계에서 결정)
  • 계절감 (봄 꽃, 여름 빛, 가을 낙엽, 겨울 눈)

운영 원칙

핵심: 같은 모델인지 한눈에 알아볼 수 있어야 합니다. 헤어를 바꾸고 메이크업을 바꿔도 "이 사람"이라는 동일 인물성이 유지되어야 합니다. 이를 위해 Base Identity는 Face Embedding 벡터로 고정하고, 모든 생성 결과를 이 벡터와 비교해 동일 인물성을 자동 검증합니다.

AI 모델 생성 파이프라인

AI 모델 1명을 완성하기까지 6단계를 거칩니다. 각 단계는 이전 단계의 산출물을 검증한 뒤 진행합니다.

1. 페르소나 설정 → 2. 얼굴 시드 생성 → 3. 멀티앵글 확장 → 4. 체형/전신 확정 → 5. 일관성 검증 → 6. Reference Set 확정

1단계: 페르소나 설정

입력 운영자가 정의

이름가상 한국 이름 (예: 윤서아). 실존 인물과 겹치지 않도록 확인
나이만 19~35세 범위. 10대 후반은 반드시 만 19세 이상 성인
스타일 축"오피스 미니멀", "스트릿 캐주얼" 등 핵심 패션 정체성
얼굴 인상"시원한 눈매 + 날카로운 턱선", "둥근 볼 + 부드러운 인상" 등 텍스트 기술
체형키(cm), 체형 타입(슬림/보통/탄탄), 어깨 타입(좁은/보통/넓은)
피부톤한국 기준 웜톤/쿨톤/뉴트럴, Fitzpatrick II~IV
기본 헤어기본 상태 헤어 (변형 전 디폴트)
기본 메이크업기본 상태 메이크업 (변형 전 디폴트)
말투SNS 캡션/숏츠 자막에 쓸 텍스트 톤
금지 연출교복, 미성년 암시, 과노출, 실존 인물 유사 등

2단계: 얼굴 시드 생성

핵심 모델의 DNA를 만드는 가장 중요한 단계

생성 수량후보 얼굴 50장 생성 → 운영자가 1장 선택
프롬프트페르소나 텍스트 기술 + 인상/나이/피부톤/헤어 키워드
해상도정면 얼굴 512×512 → 선택 후 1024×1024 업스케일
선택 기준실존 인물 비유사, 자연스러운 비율, 브랜드 톤 적합, 반복 생성 가능성
거부 기준유명인 유사도 > 0.7, 비대칭 과도, 피부 결함, uncanny valley
실존 인물 유사 검증: 선택 즉시 유명인 Face DB(한국 연예인/인플루언서 10,000명+)와 cosine similarity 비교. 0.7 초과 시 자동 차단 + 알림. 0.5~0.7은 경고 표시 + 운영자 재확인.

3단계: 멀티앵글 확장

확장 선택된 얼굴을 다양한 각도로 확장

각도수량용도검증
정면 0°5장상세페이지, 프로필시드 얼굴과 embedding 일치도 > 0.90
좌 3/4 (30°)4장룩북, SNS 피드귀/턱선/광대 일관성 확인
우 3/4 (330°)4장룩북, SNS 피드좌측과 대칭 일관성
좌 측면 (90°)3장코/턱 라인 확인코 높이, 턱선 각도 일관
우 측면 (270°)3장코/턱 라인 확인좌측면과 대칭
약간 위 (15° 틸트)3장자연스러운 카메라 각도이마/눈 비율 유지
약간 아래 (345° 틸트)2장숏츠 셀피 각도턱 비율 자연스러움

합계: 24장. 이 중 운영자 승인 20장 이상이 Reference Set의 얼굴 파트가 됩니다.

4단계: 체형/전신 확정

전신 얼굴 + 체형 결합

전신 생성확정 얼굴로 전신 이미지 30장 생성
포즈기본 서기, 걷기, 앉기, 기대기, 돌아보기 (6종 × 5장)
의상뉴트럴 의상 (흰 티+데님/검정 원피스/회색 니트) — 의상이 아닌 체형 확인 목적
체형 검증키 비율(머리:전신 = 1:7~1:8), 어깨 너비, 팔 길이, 다리 비율 일관성
승인 기준20장 이상 승인 → 전신 Reference Set 완성

5단계: 일관성 검증

Face Embedding 검증

모든 승인 이미지에서 얼굴을 추출하여 시드 얼굴과 cosine similarity 계산. 0.88 미만은 자동 탈락.

체형 일관성 검증

전신 이미지에서 키포인트(어깨, 허리, 엉덩이, 무릎) 비율이 기준치 ±5% 이내.

피부톤 일관성

얼굴/팔/다리 피부톤 CIE ΔE < 8. 조명 차이를 감안해도 같은 피부로 보여야 합니다.

실존 인물 최종 대조

전체 승인 세트를 다시 한번 유명인 DB와 대조. 한 장이라도 0.7 초과하면 해당 각도 재생성.

6단계: Reference Set 확정

최종 산출물 (모델 1명당):
• 얼굴 Reference: 20장 이상 (다양한 각도/표정)
• 전신 Reference: 20장 이상 (다양한 포즈/뉴트럴 의상)
• Face Embedding 벡터: 512차원 (동일 인물성 검증 기준값)
• 체형 키포인트 기준치: 어깨/허리/엉덩이/무릎 비율
• 피부톤 기준값: CIE Lab (L*, a*, b*)
• 메타 정보: 이름, 나이, 스타일 축, 금지 연출, 기본 헤어/메이크업
상태: base_confirmed → 이후 변형 시스템으로 진입 가능

정체성 고정 메커니즘

"이 모델은 항상 이 사람으로 보여야 한다"를 기술적으로 보장하는 구조입니다. 헤어를 바꾸고 메이크업을 바꿔도 Face Embedding 유사도가 0.88 이상이어야 통과합니다.

고정 요소기준값 저장검증 방법임계값위반 시
얼굴 골격512차원 embeddingcosine similarity≥ 0.88자동 폐기 + 재생성
피부톤CIE Lab (L*, a*, b*)ΔE2000≤ 8.0경고 + 운영자 판단
체형 비율키포인트 비율 벡터유클리드 거리≤ 5%경고 + 운영자 판단
눈 색상RGB 범위색상 거리ΔE ≤ 5자동 보정 시도
입술 형태랜드마크 비율비율 비교≤ 8%경고
왜 0.88인가: 0.90 이상은 같은 포즈/표정에서만 달성 가능해 변형 자유도가 떨어짐. 0.85 이하는 다른 사람으로 인식될 위험. 0.88은 헤어/메이크업 변경을 허용하면서도 동일 인물성을 유지하는 실무 임계값. P0 운영 데이터로 조정 가능합니다.

변형 시스템 (Style Layer)

운영자가 AI 모델의 스타일을 쉽게 변경하는 핵심 기능입니다. 각 변형 요소는 파라미터 슬라이더 + 프리셋 선택 두 가지 방식으로 조정할 수 있습니다.

AI 모델 관리 콘솔 UI

운영자가 AI 모델을 생성하고, 스타일을 바꾸고, 프리셋을 관리하고, 버전을 추적하는 실제 화면입니다.

화면 1: 모델 대시보드

메인 화면
  • 6명 모델 카드 그리드 (현재 적용 중인 스타일 썸네일)
  • 각 카드: 이름, 나이, 현재 헤어/메이크업 요약, 최근 사용일, 생성 콘텐츠 수
  • 필터: 스타일 축, 연령대, 최근 사용 순
  • 버튼: "새 모델 생성", "스타일 변경", "히스토리"

화면 2: 모델 생성 위자드

6단계 스텝
  • Step 1: 페르소나 기본정보 폼 (이름/나이/인상/체형)
  • Step 2: 얼굴 시드 — 50장 갤러리에서 1장 선택
  • Step 3: 멀티앵글 — 자동 생성 후 승인/재생성
  • Step 4: 전신 — 체형 확인 + 승인
  • Step 5: 일관성 검증 리포트
  • Step 6: Reference Set 최종 확정

화면 3: 스타일 에디터

핵심 기능
  • 좌측: 현재 모델 미리보기 (실시간 반영은 P1)
  • 우측: 헤어/메이크업/액세서리/표정 탭
  • 각 탭: 슬라이더 + 드롭다운 + 프리셋 원클릭
  • 하단: "시험 생성" → 2장 미리보기 → "적용" 또는 "되돌리기"
  • 사이드: 프리셋 라이브러리 패널 (드래그로 적용)

화면 4: 버전 히스토리

타임라인
  • 세로 타임라인: 각 버전 날짜 + 변경 내용 + 썸네일
  • 버전 간 비교: 두 버전 선택 → 파라미터 diff + 이미지 비교
  • 복원 버튼: 과거 버전 스타일 파라미터 복원
  • 즐겨찾기 ★: 자주 쓰는 버전 상단 고정

화면 5: 프리셋 관리

라이브러리
  • 카테고리별 정리: 계절, 상황(출근/데이트/캐주얼), 모델별
  • 프리셋 카드: 썸네일 + 파라미터 요약 + 검증 상태
  • 새 프리셋 만들기: 현재 스타일 에디터 상태를 저장
  • 공유: 모델간 프리셋 복사 (헤어만/메이크업만/전체)

화면 6: 일괄 적용

효율
  • 캠페인/시즌 단위로 모델 여러 명에 같은 톤 적용
  • 예: "가을 캠페인" → 6명 모두 가을 무드 프리셋 일괄 적용
  • 각 모델별 시험 생성 + 일괄 embedding 검증
  • 실패한 모델만 개별 조정

상황별 적용 시나리오

실제 운영에서 AI 모델 스타일을 바꿔야 하는 상황과 대응 방법입니다.

상황변경 범위프리셋 사용절차소요 시간
시즌 전환 (봄→여름) 헤어 스타일링 + 메이크업 톤 + 표정 계절 프리셋 적용 프리셋 선택 → 시험 생성 → 승인 → 전 상품 코디에 적용 10~20분/모델
특별 캠페인 (밸런타인 데이) 메이크업(레드립) + 액세서리(하트 귀걸이) + 표정(웃음) 커스텀 프리셋 새로 만들기 스타일 에디터에서 수정 → 저장 → 캠페인 기간만 적용 15~30분/모델
상품 카테고리별 스타일 오피스 상품 → 오피스 프리셋 / 캐주얼 → 데일리 프리셋 기존 프리셋 선택 코디 매칭 시 상품 카테고리에 따라 프리셋 자동 추천 2~5분 (프리셋 선택만)
헤어스타일 대폭 변경 (숏컷 전환) 헤어 전체 재설정 Major 버전 업 (v2.0) 스타일 에디터 → 시험 생성 8장 → embedding 전수 검증 → 확정 30~60분
트렌드 반영 (유행 메이크업) 아이 메이크업 위주 변경 프리셋 수정 또는 신규 레퍼런스 이미지 참고 → 파라미터 조정 → 시험 → 적용 15~25분
숏츠용 다이내믹 표정 표정/시선만 변경 표정 프리셋 (검증 불필요) 표정 탭에서 선택 → 바로 생성 1~3분
과거 스타일 복원 이전 버전 전체 버전 히스토리에서 복원 히스토리 → 해당 버전 선택 → "이 스타일로 복원" → 확인 3~5분
자동 추천 (P1 목표): 코디 매칭 단계에서 상품 카테고리·시즌·타깃 연령에 따라 해당 모델의 가장 적합한 프리셋을 자동 추천. 예: "겨울 코트 상품 + 윤서아" → "겨울 미니멀" 프리셋 자동 제안.

가드레일 & 리스크 관리

실존 인물 유사

  • 생성 시마다 유명인 Face DB 대조
  • cosine similarity > 0.7 → 자동 폐기
  • 0.5~0.7 → 경고 + 운영자 확인
  • DB: 한국 연예인/인플루언서 10,000명+
  • 월 1회 DB 업데이트

10대 후반 모델 보호

  • 만 19세 성인 페르소나만 허용
  • 교복, 미성년 암시 프롬프트 자동 차단
  • 선정적 메이크업/표정 조합 경고
  • 모든 콘텐츠에 성인 설정 표시

동일 인물성 깨짐

  • 변형 후 embedding < 0.88 → 적용 차단
  • 안경/모자 착용 시 임계값 0.85로 완화
  • 연속 3회 실패 → 해당 변형 조합 비호환 알림
  • 비호환 파라미터 조합 DB 축적 → 자동 경고

AI 표시 의무

  • 모든 생성 이미지 EXIF에 AI 생성 태그
  • SNS 게시 시 프로필/캡션에 AI 표시
  • 상세페이지 AI 표시 블록 필수
  • 표시 누락 시 판매 반영 차단

단계기간작업산출물완료 기준

P0-44~5주 버전 관리 + 일괄 적용 + 6명 완성 버전 히스토리, 복원, 일괄 프리셋 적용 6명 모델 × 5종 프리셋 = 30개 스타일 검증 완료
P16~8주 실시간 미리보기 + 자동 프리셋 추천 + 상품 연동 스타일 에디터 실시간 반영, 코디 단계 자동 추천 운영자가 프리셋 선택 없이 상품만 넣으면 최적 스타일 자동 적용

P0 파일럿 목표

모델 6명 × 프리셋 5종 = 30개 스타일 확정.
각 스타일에서 정면+3/4 시험 생성 → 동일 인물성(embedding ≥ 0.88) 검증 통과.
운영자가 프리셋 한 클릭으로 스타일 전환 후 5분 이내 코디 매칭 진입 가능.
모든 버전 히스토리 추적 가능, 과거 스타일 복원 3클릭 이내.
