GoodsCode Prefix → 카테고리 자동 분류

V1 상품코드(GoodsCode)의 영문 prefix가 이미 카테고리 역할을 합니다. V2 product_categories 테이블에 매핑 데이터가 0건이지만, prefix 파싱으로 자동 분류가 가능합니다.

자동 분류 알고리즘

  1. GoodsCode에서 영문 prefix 추출 (정규식: /^([a-zA-Z]+)/)
  2. prefix를 소문자 변환 후 매핑 테이블 조회
  3. 매칭 실패 시 → 기타(11)로 분류 + 관리자 알림
  4. 분류 결과를 product_categories 테이블에 INSERT (V2 정규화)

※ 추후 도매/소매 서비스 확장 시 이미지 업로드 흐름도 이 분류 체계를 따르도록 설계합니다.

코디 조합 규칙

주상품의 카테고리에 따라 AI가 자동으로 코디 세트를 구성합니다.

주상품 카테고리필수 코디 슬롯선택 코디 슬롯코디 세트 수
상의 (bl/t/nt/nb)하의 1개아우터, 가방, 악세서리, 신발3~5세트
하의 (pt/sk)상의 1개아우터, 가방, 악세서리, 신발3~5세트
원피스 (ops)없음 (단독 착용)아우터, 가방, 악세서리, 신발3~5세트
아우터 (jk/cd/jp)상의 1개 + 하의 1개가방, 악세서리, 신발3~5세트
셋업 (set)없음 (세트 착용)아우터, 가방, 악세서리, 신발2~3세트

코디 아이템 선택 우선순위

  1. 뉴톡 자체 상품 (최우선) — 동일 시즌코드(suffix), 가격대 유사, 색상 보색/유사색 우선
  2. 뉴톡 다른 시즌 상품 — 카테고리 매칭은 되지만 시즌이 다른 뉴톡 상품
  3. AI 가상 아이템 생성 — 뉴톡에 해당 카테고리 상품이 부족할 때만 사용. 가상 아이템은 비판매로 표시

AI 가상 아이템 생성 조건

  • 해당 카테고리 뉴톡 상품이 5개 미만일 때만 발동
  • 가상 아이템에는 [AI 스타일링] 라벨 필수 부착
  • 생성된 가상 아이템은 상세페이지에서 "유사 상품 추천" 영역에 표시 (직접 판매 불가)
  • 추후 뉴톡에 유사 실제 상품이 등록되면 자동 교체 알림

AI 코디 추천 알고리즘 상세

단계처리입력출력
1. 색상 추출주상품 제품컷에서 상위 3색 추출제품컷 이미지HEX 색상 3개 + 색상 계열
2. 스타일 분석상품명 + 이미지로 스타일 키워드 추출상품명, 이미지캐주얼/포멀/스트릿/페미닌 등
3. 시즌 매칭GoodsCode suffix에서 시즌코드 추출GoodsCodeS/S, F/W, 간절기 등
4. 후보 필터같은 시즌 + 보색/유사색 + 스타일 유사도전체 상품 DB카테고리별 후보 10~20개
5. 조합 생성후보에서 최적 조합 3~5세트 생성후보 리스트코디 세트 (JSON)
6. 가상 보완부족 카테고리에 AI 가상 아이템 생성미충족 슬롯가상 아이템 이미지 + 메타

비즈니스 룰 & 엣지케이스

뉴톡 상품 우선 규칙

  • 코디 아이템의 뉴톡 실제 상품 비율이 70% 이상이어야 승인 가능
  • 가상 아이템은 코디당 최대 2개까지
  • 가상 아이템이 포함된 코디에는 "일부 AI 스타일링 아이템 포함" 표시

이미지 품질 가드레일

  • V1 제품컷 최소 해상도: 800×800px (미달 시 AI 업스케일링 자동 적용)
  • 배경 제거 품질 검사: 누끼 처리 후 외곽 아티팩트 자동 감지
  • 색상 왜곡 검사: 원본 대비 색차 ΔE ≤ 5 이내 유지

금지 조합

  • 동일 카테고리 중복 금지 (예: 상의 2개 동시 코디 불가)
  • 원피스 + 하의 동시 코디 금지
  • 셋업 + 상의/하의 개별 교체 금지 (셋업은 세트 유지)
  • 가격대 4배 이상 차이 아이템 조합 시 경고 표시

시즌 코드 체계

GoodsCode suffix에서 시즌 코드를 추출합니다:

  • k5a ~ k5c: 2025 S/S ~ F/W
  • k6x: 2026년 시즌
  • c9x: 구시즌 (코디 후순위)
  • 시즌 코드 없는 상품: 사계절 아이템으로 간주
