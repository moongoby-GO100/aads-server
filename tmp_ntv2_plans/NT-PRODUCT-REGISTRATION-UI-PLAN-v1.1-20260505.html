NTV2 상품등록 UI 수정기획 v1.1
목적 흐름 UI 필드 확인질문 구현순서

상품등록은 판매글 작성이 아니라 상품 마스터를 만드는 업무입니다.

NTV2 상품등록은 도매 직접등록, 뉴톡 관리자 대행등록, 촬영서비스 후 등록, 뉴톡 자체 소비자 판매를 모두 수용해야 합니다. 따라서 첫 화면에서 등록 목적을 선택하고, 목적에 따라 필수 필드와 후속 업무가 달라져야 합니다.

상품등록 목적 정의

도매 직접등록

원칙 플로우

도매회원이 자기 상품을 직접 등록하고, 뉴톡은 검수/승인/채널 배포를 담당합니다.

  • 소유자: 도매회원
  • 필수: 도매처, 도매상품명, 도매가, 옵션, 기본 이미지
  • 후속: 뉴톡 검수, B2B 공개, 마켓 CSV/이미지 다운로드

뉴톡 관리자 대행등록

초기 운영 핵심

초기 도매가 등록하지 않으므로 뉴톡 관리자가 도매 상품을 대신 상품 마스터로 생성합니다.

  • 소유자: 도매처 또는 뉴톡 대행 계정
  • 필수: 대행 사유, 도매처 매핑, 원본 출처, 가격 산식
  • 후속: 도매 확인 요청, 검수 완료 후 공개

촬영서비스 후 등록

V1 샘플관리 반영

샘플 입고, 촬영 요청, 촬영 산출물, 상세페이지 제작을 거쳐 상품으로 전환합니다.

  • 소유자: 도매처 또는 뉴톡 대행
  • 필수: 샘플 입고, 촬영 요청 컬러, 참고사진, 컨셉, 상세페이지 상태
  • 후속: 촬영 완료, 상품정보 보강, 판매 채널 배포

뉴톡 자체 소비자 판매

자사 판매

뉴톡이 직접 판매 책임을 지는 상품입니다. 소비자몰 가격, 재고, 배송, CS 정책이 필수입니다.

  • 소유자: 뉴톡
  • 필수: 판매가, 소비자가, 재고, 배송/반품 정책, 노출 채널
  • 후속: 소비자몰 공개, 주문/정산/CS 추적

등록 흐름

1. 목적 선택도매 직접, 관리자 대행, 촬영 후 등록, 뉴톡 직판매 중 선택
2. 소유/출처 확정도매처, 입점업체, 계약코드, 등록자, 원본 출처
3. 상품 마스터 입력카테고리, 브랜드, 상품명, 코드, 가격, 옵션
4. 촬영/콘텐츠 입력샘플 사진, 촬영 요청, 이미지, 상세정보
5. 검수/승인필수값, 이미지, 가격, 법정고시, 채널 공개 조건 확인
6. 판매/배포B2B, 자사몰, 소비자몰, 외부 마켓별 공개

역할별 화면 설계

뉴톡 관리자 상품등록

  • 등록 목적 선택 카드가 첫 화면
  • 도매처 검색, 임시 도매처 생성, 계약코드 매핑
  • V1 샘플등록 수준의 전체 필드 접근 가능
  • 필수값 누락 시 검수 요청 차단
  • 도매 확인 요청과 촬영 작업 생성을 액션으로 제공

도매회원 상품등록

  • 내 도매처는 자동 지정, 소유자 변경 불가
  • 초기에는 간편등록 모드 제공: 상품명, 도매가, 옵션, 대표이미지
  • 상세정보/상품정보고시는 나중에 보강 가능
  • 뉴톡 촬영서비스 신청 버튼을 등록 흐름 안에 배치
  • 검수 상태와 반려 사유를 상품별로 노출

촬영팀/콘텐츠팀 작업 화면

  • 상품등록 초안에서 촬영 작업 자동 생성
  • 샘플 입고, 촬영예정일, 반납일, 컨셉, 요청 컬러 관리
  • 촬영 산출물을 상품 이미지/상세페이지로 바로 연결
