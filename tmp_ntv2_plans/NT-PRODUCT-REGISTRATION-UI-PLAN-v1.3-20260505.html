V1 운영 상세이미지 등록, 정렬, HTML 생성, 외부몰/소매 엑셀 제공 흐름을 V2 상품등록에 반영하기 위한 기획서

1. 결론

상세이미지 등록은 상품등록의 필수 단계로 포함해야 한다. V1에서는 원본 이미지 업로드, 상세 이미지 정렬, 스킨별 HTML 생성, 단하루 상품설명 저장, 소매 엑셀 제공이 하나의 상품 판매 가능 상태를 만드는 핵심 파이프라인이다. V2에서 단순 `product_images` 업로드로만 대체하면 V1 대체가 불가능하다.
판정 내용 근거
필수 반영 원본 이미지 등록, 썸네일 생성, 상세 정렬, PC/MO 스킨, HTML 생성, CDN 전송, 엑셀 반영을 상품등록 워크플로우에 포함 V1 코드와 `bag513k64` 운영 데이터 실측
현재 V2 부족 V2는 `product_images.type = product_cut/model_cut/detail`과 `product_details.html_content`만 있어 V1의 정렬 슬롯, 생성 산출물, 스킨, 전송 이력, 엑셀 제공 상태가 없음 V2 마이그레이션/컨트롤러 확인
통합 방향 상품등록 화면 안에 `이미지 작업실` 탭을 만들고, 이미지 원본 저장소와 판매 상세 산출물을 분리 관리 V1의 `/products/goods_img`와 `/products/goods_img_sorting_test1` 분리 구조 계승

2. V1 상세이미지 운영 흐름 확인

1. 상품코드 생성/상품 기본정보 샘플등록 또는 상품수정에서 `GoodsCode`, 상품명, 가격, 옵션, 소재, 원산지, 태그, 배송비를 저장한다. DB: `goods`, `goods_detail`
2. 원본 이미지 등록 `/products/goods_img/{GoodsCode}`에서 이미지 다건 업로드, 썸네일 생성, 압축, 파일 수 관리가 이루어진다. 파일: `data/files/goods/goodscode/img/{GoodsCode}`
3. 상세 이미지 정렬 `/products/goods_img_sorting_test1/{GoodsCode}`에서 관리 이미지 중 인트로/상세/마무리 영역으로 드래그 정렬한다. DB: `GoodsSortImg1~3`
4. 상세페이지 이미지 저장 `shop.newtalk.kr/goods/detail_save`가 스킨을 적용해 이미지 섹션을 생성하고 `images_save_end`가 저장 완료 처리한다. 산출물: `{code}_03.jpg` 등
5. 외부몰/소매 제공 생성된 HTML이 `DanharooDescription`에 저장되고, 뉴톡 엑셀의 단하루상품설명 컬럼으로 제공된다. 엑셀: `goods_select_newtalk_make`

5. 역할별 의존성

도매
상품 기본정보, 원가, 옵션, 소재/원산지, 재고/배송 조건 제공
초기에는 등록을 안 할 가능성이 높으므로 뉴톡관리자 대행등록 흐름 필요
촬영팀
원본 이미지 업로드, 파일명 정리, 이미지 정렬, PC/MO 상세 산출물 생성
상품 기본정보와 상품코드가 선행되어야 이미지 디렉터리와 산출물 생성 가능
뉴톡관리자
대행등록, 촬영 결과 검수, 상세 HTML 승인, 외부몰/소매 제공 상태 관리
모든 상태를 한 화면에서 볼 수 있어야 V1을 대체 가능
소매
상품 탐색, 상세 이미지 다운로드, 엑셀 다운로드, 편집숍 등록
상세 HTML과 이미지 라이선스/구독 권한이 확정되어야 제공 가능
소비자
편집숍 또는 뉴톡 직접판매 상품 상세 열람/구매
승인된 PC/MO 상세페이지와 대표 이미지가 있어야 판매 전환 가능

7. 구현 우선순위

우선순위 작업 완료 기준
P0 V1 이미지/상세 HTML 읽기 전용 미러링 API `bag513k64` 기준 원본 파일 수, 정렬 슬롯, HTML, 스킨, 생성 이미지 목록을 V2 관리자에서 조회
P0 V2 상품상세에 이미지 작업실 탭 추가 원본 이미지, 대표 이미지, 상세 이미지, 생성 산출물, CDN 상태가 한 화면에 표시
P1 상세페이지 빌더 데이터 모델 추가 정렬 슬롯과 PC/MO 스킨을 V2 DB에 저장하고 버전 관리
P1 HTML 생성/미리보기 워커 V1 `detail_save`와 동일한 결과물을 V2에서 생성하고 `html_content`에 저장
P2 소매 엑셀/외부몰 제공 통합 승인된 상세 HTML이 소매 엑셀과 편집숍에 동일하게 반영

8. 미결정 질문

  • V2에서 PC/MO 스킨은 V1 스킨 1~8을 그대로 유지할지, 초기에는 대표 스킨 1개로 통합할지 결정이 필요하다.
  • 상세 HTML 생성은 V1처럼 이미지 합성 파일을 생성할지, V2에서는 HTML/CSS 기반 렌더링을 원본으로 두고 필요한 채널에만 이미지 합성을 할지 결정이 필요하다.
  • 소매 엑셀 제공 시 이미지 사용 권한은 구독 등급별 제한을 적용할지, V1처럼 다운로드 로그 중심으로 관리할지 결정이 필요하다.
