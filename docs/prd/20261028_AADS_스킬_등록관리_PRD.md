## 2. 대상 사용자와 경로

- 대상: 대표님(스킬 확인·승인), 채팅·러너 세션(스킬 찾기·실행).
- 첫 진입: 대시보드 좌측 메뉴 "스킬" → `/skills` 목록. 채팅에서는 "스킬로 해줘/어떤 스킬 있어" → 스킬 찾기 결과 카드.
- 반복 사용: 프로젝트·위험등급 필터로 찾고, 상세에서 버전·최근 실행 결과를 본다. read 등급은 바로 실행, 그 외는 승인 후 실행.
- 실패 복구: 실행 실패 시 상세에 오류·입력·근거를 남기고 "다시 실행"·"이전 버전으로 되돌리기" 제공. API 실패 시 빈 화면이 아니라 사유와 재시도.

## 3. 요구사항

### 3-1. 정본 일원화 (CAT)
| ID | 요구사항 | 완료기준 |
|---|---|---|
| CAT-1 | DB `ops_skill_library` 를 정본으로 한다. 파일 스킬(.claude/skills/*/SKILL.md)은 `source_path` 로 등록(가져오기 스크립트, 멱등, dry-run 기본) | dry-run 목록 16건 + apply 후 DB 행 존재 |
| CAT-2 | 파일과 DB 내용 해시가 다르면 목록에 "파일과 다름" 표시. 자동 덮어쓰기 금지 | 불일치 표시 테스트 |
| CAT-3 | 목록 API 에 버전 수·활성 버전·최근 실행(상태·시각)·실행 수 포함 | GET 응답 필드 |

### 3-2. 실행 연결 (RUN)
| ID | 요구사항 | 완료기준 |
|---|---|---|
| RUN-1 | 채팅 도구 `skill_find`·`skill_execute` 를 기존 harness 서비스 위에 노출(새 실행기 금지) | 도구 레지스트리 등록·테스트 |
| RUN-2 | risk_tier=read 는 즉시 실행, write/deploy/auth/financial 은 기존 승인 게이트(TIER_APPROVE) 통과 후 실행. 금융·배포 스킬 자동 실행 금지 | 등급별 게이트 테스트 |
| RUN-3 | 모든 실행은 `ops_skill_runs` 에 입력 해시·결과·비용·지연·근거 기록(기존 컬럼) | 실행 1건당 1행 |
| RUN-4 | 인수 검증: read 스킬 1개(`sf-video-pipeline-health` 또는 `nas-image-job-health`)를 실제 실행해 성공 1건 | `ops_skill_runs` success ≥1 |

### 3-3. 관리 화면 (UI) — `/skills`
| ID | 요구사항 | 완료기준 |
|---|---|---|
| UI-1 | 목록: 이름·설명·프로젝트·위험등급 배지·활성 버전·최근 실행 상태/시각·실행 수, 필터(프로젝트·등급·활성/비활성·출처 DB/파일), 검색 | PC·모바일 캡처 |
| UI-2 | 상세 패널: 설명·허용 도구·검증 규칙·버전 이력(active/candidate)·최근 실행 10건(입력 요약·결과·오류) | 캡처 |
| UI-3 | 동작: read 등급 "실행"(확인창), 대표님만 "검증"·"승격"·"롤백"·"비활성"(확인창). 비CEO 는 버튼 숨김·서버 403 | 권한 테스트 |
| UI-4 | 빈 상태·로딩·오류(다시 시도) 상태, 업무명 표시(내부 slug 는 보조 표기) | 캡처 |
| UI-5 | 좌측 메뉴에 "스킬" 추가(관리 메뉴 영역) | 캡처 |

## 4. 비범위
- 새 스킬 실행 엔진·새 테이블 생성 없음(기존 harness 재사용).
- 파일 스킬 자동 동기화(양방향) 없음 — 가져오기만.
- 금융·배포 스킬의 무승인 실행 없음.

## 5. 단계
| 단계 | 내용 | 실행 | 의존 |
|---|---|---|---|
| S1 | 서버 CAT-1~3, RUN-1~3 + 테스트, 가져오기 스크립트 dry-run | 러너(aads-server, PUSH_ONLY) | 없음 |
| S2 | 화면 UI-1~5 | 러너(aads-dashboard, PUSH_ONLY) | S1 계약 |
| S3 | 배포(서버→대시보드 블루그린) + 가져오기 apply + RUN-4 | 오비스 | S1·S2 |
| S4 | 대표님 화면 확인 | 대표님 | S3 |

## 6. 리스크
| 리스크 | 대응 |
|---|---|
| 스킬 실행으로 운영 변경 | read 외 등급은 승인 게이트, 금융·배포 자동 실행 금지 |
| 파일 스킬 덮어쓰기 | 가져오기만, 불일치 표시 |
| 학습 사이트 스킬 품질 | 목록에 출처·검증 상태 표시, candidate 는 실행 버튼 비활성 |

## 7. 완료 판정
1. `/skills` 운영 화면 PC·모바일 캡처(목록·상세·실행 결과).
2. `ops_skill_runs` 성공 1건 이상(read 스킬).
3. 파일 스킬 16개가 DB 목록에 출처=파일로 보임.
4. 서버·대시보드 테스트 PASS, 배포 기록 success.
