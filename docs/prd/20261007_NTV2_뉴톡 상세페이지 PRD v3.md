### 2.2 한계 — 수치를 읽을 때 주의할 점

1. **쇼핑몰 간 표본 편중이 큽니다.** 조각 수가 ggsing 287·hotping 262·66girls 183·slowand 168·dabagirl 117·lagirl 60·chuu 33·blackup 15·attrangs 13·imvely 3개입니다. 전체 비율은 긴 페이지(앞 5곳)가 좌우하고, 뒤 5곳의 "쇼핑몰별 패턴"은 3~60조각 위에 있어 **유형 단정이 안 됩니다** [비전 판독, 2026-10-07].
2. **조각 ≠ 컷.** 1600px 조각 하나에 여러 컷이 들어 있을 수 있어, 비율은 "지면 비율"에 가깝고 "컷 개수 비율"이 아닙니다 [추정].
3. **조각 하나에 유형 하나(dominant)만 셉니다.** 작은 글씨의 정보 블록은 dominant 가 되기 어려워 **과소 검출**됩니다. 사이즈표는 dominant 로 3조각(3페이지)뿐인데, OCR 글자에서 사이즈 관련 키워드는 16/29 페이지, 소재·세탁 키워드는 13/29, 배송·교환 키워드는 8/29, 모델 키·착용 사이즈 키워드는 9/29 페이지에서 나옵니다 [OCR 키워드 점검, 2026-10-07; 키워드가 느슨(cm·어깨 등)해 과대 가능]. → **정보형 블록(사이즈·소재·배송)의 위치·비율은 이 벤치로 확정할 수 없습니다.**
4. **"코디 제안"은 라벨이 넓습니다.** dominant 12.1%인데 복수 라벨(types)에는 조각의 약 절반(573/1,141)에 들어갑니다 [비전 판독, 2026-10-07]. 다른 상품 추천과 스타일링 착용컷이 섞였을 수 있습니다 [추정].
5. **순서 패턴의 표본이 1~3페이지입니다.** "가장 흔한 시작 순서" 1위도 3/29 페이지(제품 단독) 뿐이라 시작 순서의 규칙성은 약합니다.

### 2.3 교차검증 결과 (Sonnet 불가, 원인 확인됨)

- **Sonnet 재판독은 하지 못했습니다.** 일치율을 산출하지 못했고, 모델 간 일치율은 **미측정**입니다.
- 원인: **모델 id 문제가 아닙니다.** 같은 20조각·같은 프롬프트에서 Haiku 는 1순위 OAuth 계정으로 정상 응답했고, `claude-sonnet-4-5`·`claude-sonnet-4-6`·`claude-sonnet-5`·`claude-sonnet-4-5-20250929`·`claude-opus-5-5` 는 모두 같은 계정에서 **HTTP 429**(rate_limit_error)가 반환됐습니다. 2순위 OAuth 계정은 모든 모델에서 **HTTP 401 "OAuth access token has been revoked"** 였습니다. Haiku 외 모델이 쓰는 쿼터가 소진되고 2순위 토큰이 폐기된 상태입니다. 중앙 호출 함수는 429 재시도 후 LiteLLM 체인으로 넘어가는데 이 체인에는 Claude 별칭이 없어 빈 응답이 되고, 그 결과가 파일럿 기록의 `empty_reply` 입니다. 04:18·04:21·04:22 KST 세 번 재시도해도 같았습니다. (근거 파일: `vision/crosscheck_20261007.json`)
- 대신 **같은 모델의 재판독 일치율**을 쟀습니다: Haiku 2회차 20조각 중 18조각이 1회차와 dominant 일치 = **90%**(n=20). 이것은 **반복성**이지 교차검증이 아닙니다. 불일치 2건은 전신↔클로즈업, 누끼↔컬러 옵션처럼 인접 유형끼리였습니다 [비전 판독, 2026-10-07].
- 사용 비용: 약 $0.03(추정치, Haiku 재판독 20조각 + 프로브). 상한 $1 이내.
- 후속: 쿼터·2순위 토큰이 복구되면 같은 20조각으로 Sonnet 일치율(기준 80%)을 먼저 재고, 7절의 정답지 검증을 합니다.

### 5.3 v3 권장 구성 — 7블록

v2 의 8단계 서사를 위 실측과 대조해 재배치했습니다. "근거 강도"는 표본(페이지 수)과 2.2의 한계를 반영한 판단입니다 — 높음 없음, 중 = 20페이지 이상에서 같은 방향, 낮음 = 표본 부족 또는 과소 검출.

| 블록 | 권장 위치 | 내용 | 필요 컷 | 근거 | 강도 |
|---|---|---|---|---|---|
| A 첫인상 | 0~10% | 대표 착용컷 1 + 한 줄 카피 | 모델 전신 | 첫 15% 안에 모델 컷 76%(22/29), 전신 평균 첫 등장 8.9% | 중 |
| B 컬러·옵션(선택) | 0~10% 상단 칩, 필요 시 말미 반복 | 컬러 칩·옵션 요약 | 컬러별 컷 | 컬러 옵션 조각의 54%가 상단 20%. 첫 조각이 컬러 옵션인 페이지 4/29 | 낮음 |

v2 와 달라진 점:

1. **코디를 증거 앞으로**: v2 는 6번째, 실측은 20~40% 구간.
2. **증거를 2단으로**: v2 는 "장점 직후 한 번", 실측은 상단 요약 + 후반 상세의 양극 분포.
3. **컬러 옵션을 상단 선택 블록으로**: v2 는 말미 "행동 유도"의 일부였음.
4. **"공감"(상황 제시) 단계 강등**: 벤치에 직접 근거가 없습니다. 설득 문구는 1.3%·34% 페이지뿐이고, 모델 착용 시리즈가 상황 제시를 겸하는 것으로 [추정] 됩니다. 카테고리별 선택 블록으로 둡니다.
5. **착용 시리즈를 명시**: v2 에는 없던, 지면 64%의 본체입니다.

### 5.5 문구·금지어(v2 유지)

상품 정보 + 컷 분석 결과로 카피 초안을 만들고 사람이 수정합니다. 사실이 아닌 표현(최저가·한정 등)은 금지어로 막습니다. 벤치 페이지의 글자는 이미지 안에 있어 OCR 이 자주 깨졌으므로(예: "가 이 자 으으아 은") 벤치의 문구를 카피 학습 자료로 쓰지 않습니다 [OCR 키워드 점검, 2026-10-07].

### 6.2 첫 실행

1. 상품 1건과 원본 사진을 올립니다(상품명·컬러·사이즈·소재·세탁 입력).
2. 컷 유형이 자동 분류되고 사람이 불량·유형을 고칩니다.
3. 시스템이 템플릿 유형(모델 중심형 기본)을 추천하고, 슬롯별로 컷을 자동 배정합니다. 부족한 슬롯은 "컷 부족"으로 표시합니다.
4. 카피 초안을 확인·수정하고 PC·MO 미리보기를 본 뒤 발행합니다.
5. 첫 실행의 기본값은 **모델 중심형 템플릿 + 인물 보정 "약"** 입니다.

### 6.3 반복 사용

- 같은 카테고리의 이전 발행본 템플릿과 슬롯 배정을 기본값으로 재사용합니다.
- 사람이 고친 컷 유형은 정답지로 쌓여 7절의 정확도 측정과 분류 개선에 씁니다.
- 새 상품마다 처음부터 고르지 않고 [이전 상품 복제] → 컷만 교체할 수 있습니다.
