공개 사이트에서 확인한 사실만 적는다 [https://www.lylon.co.kr/, 2026-09-17].

- 여성의류 자사몰(메이크샵 기반, 계정 `jjh9831`), KR/CHN/ENG/JP 4개 언어관 운영.
- 카테고리: 아우터·상의·하의·원피스·셔츠·트레이닝·레깅스·신발·가방·악세사리·디즈니
  라이선스·자체제작(LYLON)·세일·1+1.
- 상품 회전이 빠르고(신상 7%, 당일배송, 시즌오프 최대 80%), 리뷰 수백~900건대 단품이 있다.

회계적 함의 — 매입 구성이 **광고선전비 중심**인 것이 이 업태와 일치한다(페이스북·네이버·
카카오·지그재그·모비아이). 그래서 화면의 1순위 축은 매체·브랜드별 광고비 귀속이고,
견본비(라룸 등 샘플 매입)·소모품비(옷걸이·포장)·배송 관련 비용이 뒤를 잇는다.
자사몰·오픈마켓 양쪽을 쓰므로 PG 수수료가 지급수수료로 상시 발생한다.

### 4.3 데이터 경로

`atom_record`(EAV: `source_file_id` × `rec_idx` × `field_key`) 를 `rec_idx` 기준으로
pivot 해 전표 1행을 만든다. 연결은 `ceo_chat_tools_db.query_acct_database` 재사용 —
SSH 터널 + `acct_app` + 읽기전용 트랜잭션이 이미 그쪽에 있고, 자격증명을 새 모듈에서
다시 다루지 않기 위해서다(R-KEY).

### 회계적으로 가장 큰 두 건

1. **해외 광고비 부가세(V-04)** — 페이스북 결제분에 공급가액의 10% 가 부가세로 잡혀 있다.
   세금계산서가 없는 해외 매입은 매입세액공제 대상이 아니며 전자적 용역 대리납부 검토가
   필요하다. 금액이 3.5억 규모라 세액 영향이 가장 크다. **세무 확인 후 일괄 정정.**
2. **PG 귀속 사업자번호(V-05 인접)** — "쿠팡(포워드벤처스)" 전표의 사업자번호가
   한국사이버결제(113-85-21083)로 들어가 있다. PG 대행 결제라 실제 가맹점이 아니라
   PG사 번호가 붙는 것으로, 거래처원장과 세무 신고의 귀속이 전부 틀어진다.
   카드 명세서 가맹점명으로 재귀속하는 배치가 필요하다.

## 6. 보안

- **PAN 마스킹**: 카드번호는 API 응답 단계에서 앞 4 / 뒤 4 자리만 남긴다. 전체 노출
  경로를 만들지 않았다. 필요해지면 별도 권한 + 감사로그를 먼저 만들고 연다.
- **읽기 전용**: 이 릴리스는 조회만 한다. 확정·제외·전송은 다음 단계이며, 쓰기를 열 때
  `period_lock`(마감월 차단)과 `audit_event` 기록을 같이 넣는다.
- **입력 처리**: 사용자 입력은 길이 제한 + 작은따옴표 이스케이프 + 주석/세미콜론 차단을
  거친 뒤에야 SQL 리터럴이 된다. 원문 SQL 은 받지 않는다.
- **인증**: 전 엔드포인트 `Depends(get_current_user)`.
