## rev2 변경 요지

1. §6 연관 기획('현재 작업중' 아이콘)의 쟁점 4개는 **대표님이 결정하지 않았다.** 원문 근거: 세션 8bf0405a 15:24 KST 오비스 응답 "3가지와 앞서 드린 4가지에 의견을 주시면 PRD 한 건으로 합치겠습니다" → 15:33 대표님 "쟁점 6가지 모두 권장안". 6가지는 우선순위·휴면 3가지 + 자동승인 3가지(4~6번)이며, 아이콘 쟁점 4개는 번호상 포함되지 않는다. rev1 의 "🔄 판정 = 러너 실행 중 + 최근 30분 대화 활동, 미연결 칩" 표기는 권장안을 확정처럼 적은 것이므로 §6-1 미결로 옮겼다.
2. 아이콘 기획(15:21)의 "💤 = 진행중인데 24시간 활동 없음" 은 대표님이 확정한 휴면 14일(§6 #2)과 충돌한다. 💤 는 14일 휴면에만 쓴다. 24시간 무활동은 별도 표시를 두지 않는다(필요 시 §6-1 에서 결정).
3. PR-3 정렬의 🔄·⏳ 단계는 §6-1 결정 전까지 서버 판정 계약이 없다. M2 는 P0/P1/P2/💤 정렬만 확정 범위로 구현한다.
