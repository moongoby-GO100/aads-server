PRD G1~G6/G8 게이트 통과, PC/모바일 실화면 캡처, AADS 완전 차단 상태에서 로그인·조회·등록·파일·수집 성공을 통합 검증한다.

## 2. 완료 기준 (DB 정본)
PRD G1~G6/G8 통과, PC/모바일 캡처, AADS 차단 상태 로그인·조회·등록·파일·수집 성공. 브라우저 실패 시 API 폴백과 화면 미완료를 분리.

## 3. 작업 항목

전 게이트 PASS, 캡처 또는 API 폴백 증거 첨부, AADS 차단 상태에서 핵심 업무 흐름 성공.

## 5. 리스크
