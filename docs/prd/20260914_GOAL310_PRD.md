# #310 전략카드 일일 누적수익 3% — PRD·설계

## 1. 지표 정의 — 애매하면 달성 판정이 흔들린다

| 이름 | 정의 |
|---|---|
| 일일 누적수익 | 당일 실현 손익 합 ÷ 운용 자금. **슬리피지·수수료 차감 후** |
| 기준선 | 개선 착수 직전 20거래일의 같은 지표 |
| 최대 낙폭 | 당일 고점 대비 저점 하락률 |
| 달성 | 연속 5거래일 중 **3일 이상** 3% 이상, 그 기간 최대 낙폭이 기준선 이하 |

평가손익으로 재지 않는다. 체결에서 깎이는 것이 이 전략의 주된 손실원이다.

## 2. 마일스톤

순서에 이유가 있다. 앞이 안 되면 뒤가 의미 없다.

| # | 마일스톤 | 담당 | 완료 기준 |
|---|---|---|---|
| 1 | **측정 복구** | `OpsInfraOwner` | 죽은 수집·스냅샷 서비스 4건이 살아나고, 유실 구간이 문서로 확정된다 |
| 2 | **기준선 확정** | `BacktestEngineOwner` | 20거래일 기준선(누적수익·승률·손익비·낙폭)이 숫자로 나온다 |
| 3 | **손실원 진단** | `StrategyCardLead` | 손실이 진입·체결·후보 중 어디서 나는지 기여도가 숫자로 갈린다 |
| 4 | **개선안 도출** | 진단이 가리킨 담당 | 개선안과 예상 효과가 백테스트로 제시된다 |
| 5 | **교차 검증** | `BacktestEngineOwner` | 기준선 대비 개선이 확인되고, 다른 지표가 깎이지 않았음이 확인된다 |
| 6 | **실매매 반영** | `LiveTradingOwner` | **대표님 승인 후** 반영, 5거래일 관찰 |

3번이 이 목표의 분기점이다. **여기서 갈린 결과가 4번의 담당을 정한다** —
미리 정하지 않는다. 진단 없이 담당을 정하면 엉뚱한 곳을 판다.

## 3. 승인 경계

| 구분 | 내용 |
|---|---|
| 자율 | 조사·분석·백테스트·문서·교차검토 |
| **대표님 승인** | 전략 파라미터 변경 · 실매매 반영 · 배포 · 자금 설정 |
| **대표님 승인** | 마일스톤 생성·변경 · 목표 기준 변경 · 담당 추가·교체 |

앞의 것은 `live_trading_guard`, 뒤의 것은 `direction_guard` 가 **코드로**
막는다. 프롬프트에만 적어 두면 지켜지지 않는다 — 2026-09-14 하루에
에이전트가 자기 규칙을 세 번 어겼다.

다른 담당을 시켜 우회하는 것도 같은 검사를 받는다.

## 4. 진행·보고

스케줄러가 2~3분마다 돈다.

    마일스톤이 in_progress 가 되면   → 담당 세션에 지시가 들어간다
    답이 30분간 확인되지 않으면      → 재발송 (3회까지)
    3회를 넘으면                     → 텔레그램으로 대표님께
    마일스톤 완료                     → 주도 채팅창에 보고

대표님은 `/goals` 에서 담당 8명의 현재 상태를 한 화면으로 보시고,
각 담당 채팅창 위의 목표 띠에서 진행률과 맡은 마일스톤을 보신다.

개입은 세 가지다 — **전체 정지 · 방향 지시 · 되돌리기.**
대표님 지시가 주도 지시를 이긴다.

## 5. 위험과 대응

| 위험 | 대응 |
|---|---|
| 한 담당의 개선이 다른 지표를 깎는다 | 5번(교차 검증)을 건너뛰지 않는다 |
| 측정이 막힌 채 개선부터 한다 | 1·2번이 완료되기 전 4번을 시작하지 않는다 |
| 하루 운을 달성으로 센다 | 연속 5거래일 중 3일 조건 |
| 수집기가 다시 죽는다 | 1번 완료 기준에 **자동 감지·복구 확인**을 포함 |
| 주도가 방향을 바꾼다 | `direction_guard` 가 막고 승인 화면에 올린다 |

## 6. 합격 기준

1. 마일스톤 6개가 등록되고 담당이 지정된다.
2. 1·2번이 완료되어 기준선 숫자가 나온다.
3. 3번의 기여도 분해가 숫자로 제시된다.
4. 개선안이 기준선 대비 개선을 백테스트로 보인다.
5. 실매매 반영은 대표님 승인 기록이 남은 뒤에만 일어난다.
6. 연속 5거래일 중 3일 이상 3% 달성, 최대 낙폭이 기준선 이하.
