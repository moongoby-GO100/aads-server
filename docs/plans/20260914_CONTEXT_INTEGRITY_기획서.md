# 컨텍스트 무결성 — 조용한 실패를 보이게 만든다

- 작성 2026-09-14 KST
- 요청: "해당 담당업무자들이 개발 연구한 결과들을 확인 할수 있는거지?
  그리고 판단해서 진행이 가능한가?"
- 설계·구현 규격은 [PRD](../prd/20260914_CONTEXT_INTEGRITY_PRD.md)

## 1. 무엇을 확인하려다 무엇을 찾았나

#310 하네스에 담당 8명을 세웠다. `ask_session` 으로 **묻는 길**은 열렸다.
대표님이 물은 것은 그다음이다 — 묻지 않아도 서로의 결과가 보이는가.

그 길은 Auto-RAG 크로스 세션 검색이다. 코드는 처음부터 있었다.
`_search_chat_messages` 가 같은 워크스페이스의 다른 세션 메시지를 벡터로
찾아 근거로 붙인다. 구조는 정확히 맞다.

**그런데 벡터가 가짜였다.**

    chat_messages 벡터   33,140건
    그중 진짜            65건
    나머지               해시 더미

주도가 "파동엔진이 뭘 하고 있지" 를 물었을 때 붙은 근거는 난수였다.

확인하는 김에 프롬프트 쪽도 실측했더니 거기서 세 개가 더 나왔다.
넷을 나란히 두면 성질이 하나다.

## 2. 네 가지 실패, 하나의 성질

| # | 무엇이 | 증상 | 왜 안 보였나 |
|---|---|---|---|
| 1 | 임베딩 경로가 컨테이너에서 안 닿음 | 검색 결과가 이상함 | 실패 시 해시 더미를 돌려주고 **저장까지 됨** |
| 2 | LAYER4 템플릿에 escape 안 된 중괄호 | — | 예외를 호출부가 잡아 **기본 프롬프트로 대체** |
| 3 | 컴파일러에 `role=""` 전달 | — | 역할 자산 0건. **오류 아님** |
| 4 | 컴파일러에 워크스페이스 표시명 전달 | — | 프로젝트 자산 0건. **오류 아님** |

**넷 다 답이 정상적으로 나온다.** 오류 로그도 없다(2번만 세 자리 중 두
자리에서 로그가 났고, 이어쓰기 경로 한 자리는 3시간 동안 조용했다).

그리고 넷 다 **숫자로는 그럴듯하다.**

- 더미 벡터의 유사도는 0.9대로 나온다. 값이 흩어져 있으니 어떤 질문과도
  적당히 비슷하다.
- 역할이 빠진 시스템 프롬프트도 34,109자다. 길이만 보면 붙은 줄 안다.

> 조용한 실패가 시끄러운 실패보다 훨씬 비싸다. 시끄러운 실패는 그날
> 고쳐진다. 조용한 실패는 몇 달을 간다.

## 3. 왜 지금까지 몰랐나 — 구분할 수단이 없었다

더미 벡터는 진짜와 **차원도 값 분포도 같다.** 구분할 열이 없었다.

결국 찾아낸 방법은 구현 세부였다. `_dummy_embedding()` 이 8개 값을
768차원까지 되풀이해 채운다 — 그래서 1번째 원소와 9번째 원소가 같다.
구현이 조금만 달랐으면 영영 못 찾았다.

이건 운이다. 운에 기대면 안 된다. **세대를 적어 두면 된다.**

프롬프트 쪽도 같다. "자산이 몇 건 걸렸나" 를 아무도 세지 않았다.
0건이어도 조용했다.

## 4. 그래서 무엇을 만드나

원칙 셋이다.

**① 실패를 실패로 둔다.** 영구 저장하는 경로는 진짜 임베딩만 쓴다.
경로가 없으면 예외를 던진다. 그럴듯한 값으로 덮지 않는다.

**② 세대를 적는다.** 저장한 벡터가 어느 규격인지 열에 남긴다. 검색은
같은 세대끼리만 비교한다. 섞이면 조용히 나빠진다.

**③ 0건을 알린다.** 역할을 줬는데 자산이 하나도 안 걸리면 경고를 남긴다.
같은 함정에 하루 두 번 빠졌다(3번과 4번). 세 번째가 없으리란 보장이 없다.

여기에 품질 개선 하나가 붙는다. nomic-embed-text 는 작업 접두어를
요구한다 — 저장에 `search_document: `, 질문에 `search_query: `.
실측에서 구분 폭이 **4배** 차이났다.

## 5. 범위

**한다**

- `chat_messages` / `memory_facts` 에 세대 열(`embedding_ver`)
- 저장 경로를 strict 로. 더미 저장 금지
- 검색을 세대 2로 한정 (크로스 세션 3경로 + 재질문 판정)
- nomic 접두어 적용, 질문 벡터는 한 곳에서 만들어 공유
- 백필 도구 — 범위 지정 강제, 시간 상한, 재개 가능
- 프롬프트 조립: 템플릿 escape, 세션 role_key 전달, 정규화된 워크스페이스 키
- 자산 0건 경고

**안 한다**

- `memory_facts` 75,153건 재임베딩 — 실측 처리량 기준 50시간이다.
  담당 8명의 채팅 2,546건(약 2시간)이 먼저다. 별건으로 계획한다.
- 임베딩 모델 교체·GPU 도입. 동시성 실측에서 현재 설정이 이미 최적이다
  (동시 1 → 718건/시, 동시 3 → 963건/시, 동시 6 → 833건/시).

## 6. 이 일이 끝나면 대표님이 할 수 있는 것

담당에게 "파동엔진이 이번 주 뭘 했나" 를 물으면, 그 답에 **파동엔진
세션의 실제 문장이 근거로 붙는다.** 지금은 난수가 붙는다.

주도가 발굴 담당의 답을 받고 "이건 인프라 일이다" 라고 판단할 때,
그 판단의 근거로 인프라 담당이 이미 조사해 둔 내용이 올라온다.

그리고 담당이 이어쓰기를 할 때 **자기가 누구이고 누구를 부를 수 있는지**
잊지 않는다.
