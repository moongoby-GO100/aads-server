# 위치기반 출퇴근 병행 운영 기획

- document_key: `acct-location-clock-parallel-plan`
- 프로젝트: ACCT(오비서) · 작성: 2026-11-04 KST · 상태: 초안(대표 승인 전)
- 선행 PRD: `docs/prd/20260930_OBYS_ATTENDANCE_PWA_GPS_PRD.md` (반경 결정 D1)

## 1. 요약

위치기반 출퇴근 기능(동의·출근·퇴근·반경 판정)은 이미 운영 코드에 있지만 **실제로 쓰이지 않고 있다.**
지점 7곳 중 좌표가 등록된 곳이 0곳이라 모든 위치 판정이 "지점 좌표 미등록"으로 끝난다.
그래서 10월 이후 근태 105건이 전부 수기 기록이다. 이 기획은 수기 운영을 유지한 채 위치 출퇴근을
단계적으로 붙이고, 수치로 확인한 뒤에 수기 비중을 줄이는 순서를 정한다.

## 2. 현재 상태 (실측)

| 항목 | 값 | 출처 |
|---|---|---|
| 지점 수 / 좌표 등록 / 반경 지정 | 7 / 0 / 0 | ACCT DB `yeoljeong_branches`, 2026-11-04 |
| 2026-10-01 이후 근태 기록 | 105건, 전부 `source=manual`, 위치 판정 없음 | ACCT DB `yeoljeong_attendance_records` |
| 반경 규칙 | 기본 50m, 지점별 30~50m, GPS 오차가 반경보다 크면 판정 안 함 | `app/api/obys_workspaces.py` GEOFENCE_* |
| 판정 결과의 지위 | 반경 안이어도 `pending` — 최종 근태는 관리자가 확인 | `judge_geofence()` |
| 동의 | 미동의 시 위치를 수집하지 않음, 철회 가능 | `attendance/consent`, CLOCK_CONSENT_ACTIONS |
| 직원 진입 | 관리자 메뉴 "출퇴근 하기" → `clock.html` | 운영 화면 r75 E2E 2026-11-04 |

## 3. 대상 사용자와 경로

| 사용자 | 첫 실행 경로 | 반복 사용 경로 | 실패 복구 경로 |
|---|---|---|---|
| 직원 | 앱 설치 → 위치 동의 1회 → "출근" 버튼 | 앱 열기 → 출근/퇴근 한 번 누름 | 권한 거부·오차 초과 시 위치 없이 기록하고 "관리자 확인 대기"로 표시, 재측정 버튼 제공 |
| 관리자 | 지점 좌표·반경 등록(지점별 1회) | 근태 현황 → 확인대기 목록에서 일괄 확인 | 위치 판정 불가 건은 사유와 함께 목록 상단, 수기 정정 유지 |

## 4. 단계 계획

| 단계 | 범위 | 수기 운영 | 넘어가는 조건 |
|---|---|---|---|
| 0. 준비 | 지점 7곳 좌표·반경 등록 화면 확인/보완, 시범 지점 1곳 선정 | 그대로 | 좌표 등록 7/7, 시범 지점 직원 동의 완료 |
| 1. 시범 병행(2주) | 시범 지점만 위치 출퇴근 + 기존 수기 동시 기록 | 그대로 | 아래 지표 기준 충족 |
| 2. 전 지점 병행(2주) | 전 지점 위치 출퇴근, 수기는 누락·오류 건만 | 예외 처리용 | 지표 기준 2주 연속 충족 |
| 3. 위치 기본 | 위치 기록이 기본, 수기는 정정 신청·관리자 수동 등록만 | 예외 경로 | — |

## 5. 판정 지표 (단계 이동 기준)

| 지표 | 기준 | 측정 방법 |
|---|---|---|
| 위치 기록 비율 | 시범 지점 근무일의 90% 이상이 `source=pwa` | 기록 원장 집계 |
| 반경 안 판정 비율 | `geofence_result=inside` 80% 이상 | 기록 원장 집계 |
| 판정 불가 사유 | `unknown` 중 "GPS 오차" 비율을 따로 보고 | reason 분포 |
| 수기와 시각 차이 | 같은 날 수기·위치 기록 차이 5분 이내 95% | 병행 기간 대조 |
| 관리자 확인 소요 | 확인대기 건 24시간 내 처리 95% | 확인 시각 − 기록 시각 |

## 6. 리스크와 대응

| 리스크 | 대응 |
|---|---|
| 실내·지하 매장 GPS 오차가 50m를 넘음 | 판정 불가로 남기고 관리자 확인. 반경 상한 상향은 대표 결정 사항(D1 변경) |
| 위치정보 수집 동의·보관 법적 요건 | 동의·철회는 구현돼 있음. 원좌표 보관기간과 고지 문구는 **법적 검토 미완료** — 1단계 전 확인 |
| 직원이 동의를 거부 | 거부해도 출퇴근은 가능(위치 없이 기록) — 불이익 없음을 화면에 명시 |
| 수기·위치 이중 기록으로 급여 이중 산정 | 병행 기간에는 급여 초안이 확인 완료(approved) 기록만 쓰는지 사전 점검 |

## 7. 대표 결정 필요

1. 시범 지점 1곳 선정.
2. 반경 50m(D1) 유지 여부.
3. 원좌표 보관기간(예: 근태 확정 후 N일 뒤 거리·판정만 남기고 좌표 삭제).
