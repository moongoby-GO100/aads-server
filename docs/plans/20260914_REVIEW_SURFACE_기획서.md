# 어디서 확인하고 검토하는가 — 대표님의 세 자리

- 작성 2026-09-14 KST
- 대표님 질문: "담당 채팅창에 현재 진행중인 목표와 마일스톤을 표기하나?
  내가 어디서 확인하고 검토할수 있지?"

## 1. 표기한다 — 다만 얇다

담당 채팅창 대화 위에 띠가 있다.

    🎯 #310 전략카드 일일 누적수익 3% 확보   33% · 손실원 진단

지금 담기는 것은 여섯 가지뿐이다 — 목표 제목, 상태, 진행률, 맡은
마일스톤, 막힘 표시, 전체 정지 여부.

**빠진 것이 검토에 필요한 것들이다.**

| 빠진 것 | 없으면 |
|---|---|
| 마일스톤 상태(진행/확인대기/막힘) | 신고했는지 아직인지 모른다 |
| 완료 기준 | 담당이 무엇을 만족시켜야 하는지 대화에 안 보인다 |
| 제출한 근거 | 대표님이 창을 열어도 어디에 썼는지 찾아야 한다 |
| 미답 의견·수정 요청 | 대표님이 남긴 것이 처리됐는지 모른다 |
| 재알림 횟수 | 몇 번 불렀는데 답이 없는지 모른다 |

## 2. 검토할 자리가 없다 — 이것이 핵심이다

대표님이 지금 쓰실 수 있는 자리는 둘이다.

    /goals      담당별 상태 카드 — 누가 무엇을 하는지
    각 채팅창    그 담당의 대화 — 무엇을 했는지

**그런데 "지금 내가 봐야 할 것" 을 모아 주는 자리가 없다.** 목표가 여럿이고
담당이 여덟이면 어디를 봐야 할지 모른다. 대표님이 매번 훑으셔야 한다.

봐야 할 것은 성격이 다르다.

| 종류 | 누가 판정하나 | 급한가 |
|---|---|---|
| 완료 확인 대기 (`review`) | 주도 — 단 **주도 자신의 것은 대표님** | 막힌다 |
| 막힌 마일스톤 | **대표님** | 막힌다 |
| 승인 대기 (방향·실매매) | **대표님** | 막힌다 |
| 기한 초과 | **대표님** | 놓치면 늦는다 |
| 답 없는 의견·수정 요청 | 담당 — 대표님은 안 되고 있음을 알아야 | 조용히 묻힌다 |

앞의 넷은 **누군가 누르지 않으면 목표가 선다.** 그런데 서 있다는 것을
알 방법이 화면을 훑는 것뿐이다.

## 3. 만들 것 — 세 자리를 분명히 한다

**① 채팅창 띠 — "지금 이 담당이 무엇을 해야 하나"**

담당이 자기 대화에서 맥락을 잃지 않게. 완료 기준과 상태를 같이 둔다.
대표님도 그 창을 여시면 바로 보인다.

**② `/goals` — "이 목표가 어디까지 왔나"**

이미 있다. 담당별 카드에 근거와 확인 대기를 더한다.

**③ 새로 만드는 것: 검토함 — "지금 내가 봐야 할 것"**

목표를 가로질러 **대표님 손이 필요한 것만** 모은다. 비어 있으면
"지금 볼 것이 없습니다" 라고 적는다. 그 말이 곧 정보다.

## 4. 왜 새 화면을 만드나

`/approvals` 가 이미 있는데 왜 또 만드는가 — 승인은 그중 **한 종류**일
뿐이다. 완료 확인, 막힘, 기한 초과는 승인이 아니다.

반대로 전부 `/goals` 에 넣으면 목표를 하나 골라야 보인다. **목표가
셋이면 세 번 눌러야 막힌 것을 찾는다.**

검토함은 목표를 가로지른다. 들어가면 지금 손이 필요한 것이 전부 있다.

## 5. 하지 않는 것

- **알림 배지 남발.** 모든 변화에 빨간 점을 붙이면 아무것도 안 보인다.
  막히거나 대표님 손이 필요한 것에만 붙인다.
- **채팅창 띠를 두껍게.** 대화가 주인공이다. 띠가 화면을 먹으면 안 된다.
  자세한 것은 펼쳐서 본다.
- **검토함에 완료된 것 쌓기.** 끝난 것은 목표 화면에서 본다.
