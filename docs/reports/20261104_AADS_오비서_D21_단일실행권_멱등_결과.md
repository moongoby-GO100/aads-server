## 2. 추가한 증거 테스트

### (a) 같은 회사 실행 2개를 실제로 겹침 — `tests/integration/test_obys_collection_postgres.py`
- `test_overlapping_runs_same_company_only_holder_writes_and_other_gets_collection_in_progress`: A 를 수집 한복판에서 멈춰 세우고 B 를 시작 → B 는 `collection_in_progress`(409), 클로브 호출 0, B 의 run 행 0, 임대는 A·epoch 1 그대로이고 살아 있음. A 완료 후 item 19건·run 행은 A 소유뿐. 임대 반납 후 B 재실행은 inserted 0·unchanged 19, epoch 2.
- `test_simultaneous_start_has_exactly_one_winner_whichever_task_runs_first`: 두 태스크를 동시에 시작해 누가 이기든 승자 1·패자 1(`collection_in_progress`), 패자는 데이터 도구 호출 0, item 19, run 행 소유자는 승자 하나, epoch 1.
- `test_leases_are_per_company_so_other_company_runs_while_one_is_held`: 임대가 회사별이라 다른 회사는 막히지 않음.

- 단위 `tests/unit/test_obys_collection_scheduler.py`: `test_two_overlapping_runs_on_one_company_only_first_reaches_clobe_and_loser_keeps_hands_off_the_lease`, `test_other_company_is_not_blocked_by_a_held_lease`.

### (b) 재처리 멱등
- `test_recollecting_same_company_kind_period_does_not_add_rows_or_change_hashes[4종: bank/tax/cash/card]`: 같은 회사·종류·기간을 3회 수집해도 `item_id, source_key, item_hash, stage, first_run_id, first_seen_at` 스냅샷이 완전히 같고 inserted/revised 0, unchanged = 최초 적재 수. run 행만 늘고 `last_run_id` 는 마지막 실행 하나로 수렴.

- 단위 `test_backfill_skips_company_held_by_manual_run_with_real_lease_logic_and_does_not_hijack_it`: 기존 백필 테스트는 `run_collection` 자체를 모킹했으나, 이 테스트는 실제 `run_collection`+임대 로직을 태워 `skipped_busy` 와 "백필이 수동 임대를 가로채지 않음"(owner·epoch 불변)을 확인.

## 4. 발견 — 앱 결함 후보(코드는 고치지 않음)

수동 실행 버튼(`POST /companies/{id}/runs`)은 `instance` 를 넘기지 않아 모든 요청이 `aads-api` 이름을 쓴다. `acquire_lease` 는 같은 owner 재진입을 허용하므로(`OR owner_instance = EXCLUDED.owner_instance`), 같은 회사에 버튼을 두 번 누르면 **두 번째가 409 가 아니라 임대를 가져가고 먼저 시작한 요청이 `lease_lost` 로 멈춘다**(`test_same_instance_name_overlap_still_leaves_a_single_writer` 에서 first=`lease_lost`, second=`succeeded` 실측). 펜싱 덕에 쓰기는 항상 한 쪽뿐이고 중복 행·`running` 잔류도 없다(단언함). 다만 "겹치면 나중 것이 거절" 이라는 계약은 인스턴스 이름이 실행마다 다를 때만 성립한다.
- 앱 코드를 바꾸지 않은 이유: 재진입 문구는 기존 단위 테스트(`test_lease_sql_guard_is_in_the_service`, `test_default_instance_name_would_have_hijacked_the_manual_lease`)가 고정하고 있어 고치려면 그 테스트를 바꿔야 하고, `obys_collection_service.py` 는 다른 러너와 겹친다.
- 권고(후속): `app/api/obys_collections.py` 의 `start_run` 이 `instance=f"aads-api:{uuid4().hex[:8]}"` 처럼 요청마다 고유 이름을 넘기면 서비스·기존 테스트 변경 없이 해결된다. 적용하면 `test_same_instance_name_overlap_…` 의 단언을 409 계약으로 바꿔야 한다.
