- 범위: 커밋·리뷰·푸시까지. 운영 배포·재시작·운영 DB 마이그레이션은 하지 않았다.

## 1. 한 줄 결론

"저장했다는 문서가 채팅 링크에서 안 열린다"의 원인은 **컨테이너 경로 불일치**였고, 코드로 고쳤다(테스트 통과).
**운영 반영 전이다.** 운영 컨테이너는 아직 옛 코드이므로 운영에서 증상은 그대로 남아 있다. 규칙(R-DOC) 활성화 SQL도 스크래치 DB에서만 적용·롤백을 검증했고 운영 DB는 건드리지 않았다.

## 4. API 계약 (후속 UI가 쓸 형식)

### 4.1 정본 본문 열람 (신규)

`GET /api/v1/projects/{PROJECT}/documents/{document_key}/content?revision=<n>&approved_only=<bool>`

- 인증: 기존 정본 문서 API와 같음(테넌트·프로젝트 권한 VIEW). 다른 테넌트·다른 프로젝트 문서는 404, 권한 없으면 403.
- `approved_only=true` 이고 승인 판본이 없으면 404 `document_not_found`. draft 로 대체하지 않는다.
- 응답: `project, document_key, file_path("<key>.md"), content, size, encoding("text"), mime_type("text/markdown"), is_binary(false), format("markdown")` + `canonical{document_key, revision, revision_id, version, status, authoritative, title, content_hash, source_path}` + `view{...}`.
  기존 `/project-docs/content` 응답과 같은 최상위 필드라 뷰어가 그대로 렌더링할 수 있다.

### 4.2 도구 반환의 열람 참조 `view`

`canonical_document_register` / `canonical_document_lookup` 반환에 붙는다.

```
view = { kind:"canonical", project, document_key, revision, title, status, authoritative,
         api_path, viewer_url:null, viewer_hint, report_line }
```

- `report_line` 예: `정본 초안: 「제목」 (document_key=… rev2) — 열람: 대시보드 '문서' > '정본 문서' 탭에서 문서 키로 찾기`
- `viewer_url` 은 **의도적으로 null** 이다. 대시보드에 정본 문서 딥링크가 아직 없어 거짓 링크를 만들지 않는다.
- 파일 문서는 `file_view_ref()` 가 뷰어 링크를 주고, 열 수 없는 경로면 "열람 링크 미제공" 으로 적는다.
- 에이전트는 파일 경로를 링크처럼 적지 않고 `report_line` 을 그대로 보고에 쓴다.

### 4.3 완료 판정

- 세션 문서 목록 응답에 `canonical_documents[]` 와 `rdoc{status, documents, missing, warnings, marker}` 추가.
- 러너 잡 상세에 `rdoc_compliance` 추가(해당 시), 종료 후속 메시지에 R-DOC 줄 추가.
- `status`: `not_applicable` / `complete` / `incomplete`. `incomplete` 의 표지는 `정본 미등록(미완료)`.
- 대상은 `docs/`·`reports/` 아래 `YYYYMMDD_` 접두 문서 파일뿐이다(기존 문서 수정을 소급해 미완료로 만들지 않기 위한 정밀도 우선 설계).

### 구현 검증 (스크래치 Postgres, 운영 아님)

- 적용 → 재적용(변경 없음 notice) → 동시 편집 후 롤백 중단 → 편집 되돌린 뒤 롤백 → 롤백 재실행(변경 없음) → 적용 전 편집 시 적용 중단 → 롤백 후 재적용 → 다시 롤백. 롤백 후 md5 는 원본 `e2fcbb59…` 과 정확히 일치.
- 활성화 상태에서 실제 `PromptCompiler.compile` 을 7개 워크스페이스(CEO·KIS·GO100·SF·NTV2·NAS·AADS) × 3개 모델(claude/gpt/gemini) = 21조합 실행: 전부 `applied_assets` 에 `l1-doc-storage-rule` 포함, `compile_error` 없음, 프롬프트에 R-DOC 본문 포함.

## 교훈

- 컨테이너 경로(`/app/...`)와 호스트 마운트(`/host/...`)가 갈라진 곳에서는 "저장 성공"과 "열람 가능"이 다르다. 보고는 경로가 아니라 열람 참조로 한다.
