# 서명본 계약서 PDF '기타 기재사항' 내부 키 숨김·한글화

document_key: `acct-contract-pdf-extra-rows-20261008` (ACCT / task)

## 문제
양재혁 용역계약 3건의 서명본 PDF '기타 기재사항'에 영문 키(foreign_worker, meal_uniform_terms, memo, minor_guardian_consent, onboarding_document_summary, updated_at, health_certificate_valid_until)와 코드값 `not_applicable` 이 그대로 인쇄됐다. `extra_rows` 가 알려진 키 밖의 모든 키를 원문으로 찍고, 한글 이름은 용역계약 4개 키에만 있었다.

## 변경 (`app/services/yeoljeong_contract_pdf.py`)
- HIDDEN_FIELDS 에 `memo`, `updated_at`, `deleted_at`, `onboarding_document_summary` 추가(근로·용역 공통).
- `FREELANCER_EXTRA_LABELS` → `EXTRA_LABELS` 로 확장하고 근로계약에도 적용: 외국인 근로 여부, 미성년자 보호자 동의, 식사·복장, 보건증 유효기간, 사업장 상시근로자 규모, 식사 제공 방식, 수습 기간 + 기존 4개. 칸 이름만 바뀌고 값은 그대로다. `TERM_FIELDS` 근로계약 라벨은 건드리지 않았다.
- `display_value`: `not_applicable` → 해당 없음, 불리언 → 예/아니오. 모르는 코드값은 원문 유지.
- 안전장치: 매핑이 없는 영문 소문자_스네이크 키는 인쇄하지 않고 `logger.warning` 으로 키 이름만 남긴다(값은 로그에 남기지 않음). 한글 키 등은 종전대로 인쇄.
- 봉인 스냅샷·`snapshot_sha256`·서명 구조는 변경 없음(표시만). 같은 입력 같은 바이트 유지.

## 영향 메모
- 근로계약 '기타 기재사항'의 `workplace_size_category`·`meal_provision`·`employment_tax_type` 등은 이전엔 영문 키로 찍혔으나 이제 한글 이름으로 찍힌다(값은 기존 display_value 규칙 그대로). 기존 테스트 `test_labor_contract_labels_unchanged` 를 이에 맞게 수정.
- 매핑 없는 신규 내부 키가 스냅샷에 생기면 PDF 에서 빠진다. 계약 내용으로 보여야 하는 키라면 EXTRA_LABELS 에 이름을 추가해야 한다(경고 로그로 확인).
