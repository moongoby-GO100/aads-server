## 교훈

- 환경변수나 로컬 문자열은 승인 증거가 아니다. "비어 있지 않음"을 승인으로 읽는 게이트는 거짓 안전이다. 서버가 검증하지 못하면 막아라.
- 사후 추인은 실행자·기록된 created_by·추인자를 분리해 적고, 등록 시점으로 소급하지 않는다.
- 추인은 기존 ID 의 보존 결정이다. 새 쓰기 권한으로 재사용하지 않는다.
- ID 집합 해시는 직렬화 형식(구분자)까지 같이 적어 두어야 독립 대조가 된다. 이번 정본은 `,` 이음이었다.
- credential 이 존재한다는 것과 그 사용이 허가됐다는 것은 다르다. 소유자와 policy 를 먼저 보라.
