## 1. 결론

## 6. 감시 점검 결과 (미충족 판단의 근거)

확인한 범위에서 fb 상시 감시를 찾지 못했다.

- contabo116: root crontab·`/etc/cron.d`·systemd timer 에 fb/acct/cafe24 헬스 항목 없음(`disk_offload_cafe24.sh` 는 디스크 이전 작업이다). `aads-api-watchdog.timer` 는 있으나 AADS API 용이며, watchdog 스크립트·서비스에 fb·acct 참조 없음.
- cafe24_114: cron 에 fb/acct 감시 항목 없음(다른 서비스용 항목만 존재). r33 컨테이너 healthcheck 없음, acct-pg 는 `pg_isready` healthcheck 만 있음.
- `fb.newtalk.kr/health/live` 를 호출하는 코드는 배포 어댑터(`app/services/deploy_adapters/`)와 배포 스크립트의 **배포 시점 검증**뿐이다.
- 한계: cafe24 의 사용자 crontab 과 `/etc/cron.d` 만 봤고, 외부 SaaS 모니터나 다른 서버의 감시는 조회하지 못했다. 그래서 "감시 없음"이 아니라 "찾지 못함 = 미충족으로 기록"이다. 다른 곳에 감시가 있다면 위치를 이 표에 추가해 충족으로 바꿔야 한다.
