## 범위와 한계

- 이 문서의 표와 수치는 `scripts/aag_restore_verify_pg.py` 가 실행 중 생성한 것이다. 검증 로직의 단위테스트는 `tests/unit/test_aag_restore_verify_pg.py`(DB 없이 실행)다.
- 운영 DB 접근은 `aads-postgres` 에 대한 READ ONLY 트랜잭션과 `pg_dump` 뿐이다. 클라이언트도 쓰기 SQL 을 보내기 전에 거부한다(`is_read_only_sql`).
- 원본 수치는 스냅샷 시점 값이다. 운영은 계속 쓰기가 일어나므로 실행 이후의 라이브 row count 와는 다를 수 있다.
- 증명한 것: pg_dump/pg_restore 왕복, 16개 테이블 내용 일치, FK·인덱스·CHECK 정의 일치, 불변 트리거 동작, pointer 재구성, advisory lock 경합.
- 증명하지 못한 것: 운영 DB 자체의 라이브 복구 절차, 대용량 장기 데이터에서의 복원 시간, `pg_advisory_xact_lock` 을 쓰는 앱 ingest 코드 경로 전체(락 프리미티브만 재현).
- 정본(project_document_heads) 초안 등록은 이 작업에서 수행하지 못했다 — 정본 미등록(미완료), 열람 링크 미제공.
