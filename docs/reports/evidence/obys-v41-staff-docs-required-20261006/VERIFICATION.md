# 오비서 V4.1 — 직원 입사서류 등록 + 빈 필수값 표시·추천값 (2026-10-06)

## 변경
- 직원 현황 `승인 직원 계약` 각 행에 **[서류 등록]** — 관리자가 직원 대신 입사서류를 올린다(기존 `POST /onboarding/documents`, 새 API 없음).
  - 미제출 필수서류 목록·[이 서류 올리기], 만료일 필수 서류(보건증·외국인등록·체류자격·취업허가) 업로드 전 차단, 등록 서류 내려받기.
- 계약조건 입력 단계에 **빈 필수값 패널** — 미리보기 전부터 빈 칸을 빨갛게 표시, 칸별·일괄 **[추천값 넣기]**.
  - 추천값 출처: 오늘/계약작성일, 근무 지점, 가입 정보, 사업자 등록정보, 표준 조항, 시급제 2026 최저시급(10,320원).
  - 생년월일·주소·월급 금액은 추정하지 않음 → [직접 입력]·[입사서류 확인] 안내.
  - 추천값은 누를 때만 들어간다(자동 입력 아님).
- 직원·계약 목록에 `빈 필수값 N` 배지와 `계약 보류 N건` 안내.
