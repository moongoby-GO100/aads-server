## 변경 전 조사와 범위

초기 워크트리는 깨끗했다. 기존 구현을 유지하고 부분 수정한다. DB 마이그레이션·운영 쓰기·코드 삭제 없음.
추가 변경 사유(변경 전 기록): admin.html은 일반 관리자 로그인 목적지다. index.html만 수정하면 실제 관리자에게 기능이 닿지 않는다. 사람 업무 링크와 만료 로그인 이동만 수정한다. clock.html은 출퇴근 전용 실제 진입점으로 동일한 만료 정책이 필요하다.

## 검증 수준과 판정

정상은 코드 연결 확인을 뜻하며 브라우저 클릭 통과를 뜻하지 않는다. 수정·부족은 발견 당시 판정이며 조치 결과를 별도로 적었다. 전체 브라우저 실행은 환경 제약으로 미검증이다. 증거 없는 실행 성공을 기록하지 않는다.
