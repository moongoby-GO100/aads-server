## 표시 기준

- worked_minutes 우선, 없거나 유효하지 않으면 start_at/end_at에서 break_minutes를 차감한다. 자정 넘김을 지원한다. 시각 누락·동일 시각·잘못된 휴게는 미산출로 표시한다. 유효한 0분은 0시간 0분이다.
- 이상유형은 목록 API가 실제 반환하는 raw.memo만 표시하며, 없으면 —이다. GPS 마이그레이션에 geofence_result·위치 컬럼이 있지만 ATTENDANCE_COLUMNS에는 없으므로 GPS 판정을 추정하지 않는다. 테스트로 이 필드 선택을 고정했다.
- 서버 ATTENDANCE_STATUSES는 pending/approved/rejected이며 각각 확인필요/승인/반려로 표시한다. 미지 값은 유지한다. 상세 표에도 같은 표시를 적용한다.
- 근태 건수와 누락·수정 대기는 조회된 행 기준의 건수다. 후자는 pending/needs_review/확인 필요/확인필요/수정 대기/누락을 센다. 금액 포맷을 사용하지 않는다.
- API의 최대 500행 범위 안에서 집계하며 서버가 지원하지 않는 페이지 이동은 활성화하지 않는다. 상태·검색은 기존 화면의 로컬 필터를 사용한다.
- 성공한 0건 응답도 source.live를 유지하고 등록된 근태 기록이 없다는 문구를 표시한다.
