## pre-commit 회귀 테스트 6건 실패 원인 정밀 분석

1. **`test_pipeline_runner_deploy_gate_stale_chain.py` (1건)**:
   - 원인: 커밋 3e727648c에서 `review_rebased_aads_sha` 함수 내부의 플래그 검사를 `review_category_is_hold "$flag_category"` 호출로 변경함. 그러나 해당 단위 테스트는 격리 서브셸(`fn.sh`)을 조립할 때 `review_category_is_hold` 함수를 포함하지 않고 `review_rebased_aads_sha`만 추출하여 실행함. 이로 인해 서브셸 실행 시 `review_category_is_hold: command not found` (exit code 127)가 발생하며 실패함.
   - 조치: 테스트 하네스에서 서브셸 스크립트를 조립할 때 `_function("review_category_is_hold")`를 함께 주입하도록 보완.

2. **`test_pipeline_runner_deploy_only_approval_commit.py` (3건)**:
   - 원인: `commit_job_worktree_for_approval` 함수 내부에서 `runner_artifact_pin` 함수를 직접 호출하고 있었음. 해당 테스트는 격리 서브셸을 구성하여 `commit_job_worktree_for_approval`을 실행하는데, `STUBS`에 `runner_artifact_pin` 스텁이 정의되어 있지 않아 stderr에 `runner_artifact_pin: command not found`가 출력되고 기대치 불일치로 실패함.
   - 조치: 스크립트 측에서 `if command -v runner_artifact_pin >/dev/null 2>&1; then runner_artifact_pin ...; fi` 가드를 추가하여 함수 미정의 환경에서도 무중단 동작을 보장하고, 테스트 하네스 `STUBS`에 `runner_artifact_pin() { return 0; }` 스텁을 명시함.

3. **`test_pipeline_runner_approval_sha_stdout_contract.py` (2건)**:
