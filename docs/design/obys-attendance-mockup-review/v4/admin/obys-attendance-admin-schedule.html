③ 적용 시작일

이 날부터 새 일정으로 판정합니다. 그 전날까지는 기존 일정이 유지되고, 변경 이력에 남습니다.

④ 예외일 휴무 추가 · 대체 근무 · 근무 시간 변경

연차·병가는 예외일이 아니라 출근·결근 처리 화면에서 그날 상태로 지정합니다. 연차·병가의 급여 반영 정책 미정 — 설정 필요

⑤ 지점 공휴일·휴무일

법정공휴일 자동 반영 여부·공휴일 근무 처리 정책 미정 — 설정 필요 · 휴무일에는 근무 일정이 있어도 결근으로 판정하지 않습니다.

    표기 현재 코드 있음 현재 저장소에 화면·API 가 있는 요소 · 신규 — API·화면 없음 승인 후 설계할 요소 · 정책 미정 — 설정 필요 결정하지 않은 기준. 모든 이름·주소·좌표는 가상 데이터이며 외부 요청이 없습니다.
