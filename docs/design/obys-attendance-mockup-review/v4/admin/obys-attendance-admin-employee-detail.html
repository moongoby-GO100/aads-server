달력 보기출근·결근 처리근무 일정 설정직원 목록으로

세션 만료는 안내 화면 없이 로그인 화면으로 즉시 이동하고, 로그인 후 이 화면으로 돌아옵니다.

표기 현재 코드 있음 현재 저장소에 화면·API 가 있는 요소 · 신규 — API·화면 없음 승인 후 설계할 요소 · 정책 미정 — 설정 필요 결정하지 않은 기준. 모든 이름·주소·좌표는 가상 데이터이며 외부 요청이 없습니다.
