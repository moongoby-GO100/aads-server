신규 — API·화면 없음
  1. 1
    지점 위치·반경 설정 현재 코드 있음

    지점마다 위도·경도와 반경을 입력합니다. 반경은 기본 50m · 상한 50m(허용 30~50m, PRD r3 결정)이며, GPS 오차가 반경보다 크면 자동 확정하지 않고 확인필요로 남깁니다.

  2. 2
    직원에게 출퇴근 링크 보내기 신규 — API·화면 없음

    직원이 휴대폰에서 여는 주소: /static/apps/obys/clock.html (직원 계정 로그인 후 사용). 홈 화면에 설치하면 앱처럼 열립니다.

    직원 화면 미리보기 (C)
  3. 3
    첫 출근 확인 현재 코드 있음

    직원이 첫 출근을 누르면 오늘 현황(B)의 확인필요 대기함에 사유와 함께 나타납니다. 지금은 기록이 0건입니다.

    오늘 현황 보기 (B)
