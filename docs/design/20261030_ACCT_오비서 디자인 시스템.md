# 오비서 디자인 시스템

근거: admin.html 실제 CSS 변수와 docs/design/obys-attendance-mockup-review/v4 목업. 이 문서는 승인되지 않은 초안이다.

색은 본문 --ink #172033, 보조 --muted #667085, 배경 --bg #f4f6f9, 경계 --line #e2e8f0, 주요 작업 --blue #2457d6, 선택 배경 --blue2 #eef4ff를 사용한다. 성공 --green #16845b, 주의 --orange #c56a16, 오류 --red #c93645이며 색과 상태 문구를 함께 표시한다.

본문 14px, 입력·버튼·표·보조 문구 최소 13px, 소제목 14~17px, 화면 제목 23px의 글자 크기 단계를 사용한다. 간격은 4·6·8·12·16·24px, 카드 안쪽 여백은 16px로 한다.

입력·버튼 높이는 데스크톱과 모바일 모두 최소 44px다. 라벨 위, 입력 아래로 배치한다. 폼은 데스크톱 4열, 1050px 이하 2열 그리드를 사용하며 모바일 600px 이하는 1열이다. 체크박스는 24px, 라벨 전체 선택 영역은 44px다. fieldset은 전체 열을 차지하고 12px 여백·8px 모서리·경계선을 사용한다. legend는 14px 굵은 글씨다.

표는 별도 가로 스크롤 영역에 넣고 내용이 화면 전체를 넘치지 않게 한다. 카드와 상태 배지는 본문 대비를 유지한다. 선택한 근무표 칸은 주요 색 경계와 선택 배경으로 구분하며 aria-pressed를 제공한다.

빈 상태에는 원인과 다음 행동을 함께 쓴다: ‘승인된 직원이 없습니다. 직원 현황·초대·가입승인에서 승인하세요.’ 오류는 role=status로 원인·재시도 행동을 표시하며 저장 실패 시 입력을 유지한다. 계약 원문은 줄바꿈을 보존하고 해석 불가 시 ‘직접 등록’을 안내한다.

스타일은 people-screen 범위에 적용한다. 다른 메뉴의 전역 변수·컴포넌트 규칙은 바꾸지 않는다.
