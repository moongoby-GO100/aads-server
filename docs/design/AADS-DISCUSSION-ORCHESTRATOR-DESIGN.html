1 기능 개요

하나의 기획 주제에 대해 CEO가 직접 선택한 LLM들이 독립적으로 기획안을 작성하고, 상호 검토·비판·보완하며, CEO가 실시간으로 방향을 조정하여 양질의 최종 기획서를 도출하는 오케스트레이터 시스템.

🎯 핵심 목적
  • 단일 LLM의 편향 제거 (모델 다양성)
  • 기획 품질 향상 (경쟁적 검토)
  • CEO의 실시간 의사결정 참여
  • 검증 가능한 근거 기반 기획
⚡ v1.1 핵심 변경
  • CEO 직접 모델 선택 — 참가자별 모델 지정
  • 수동 모드 — 매 라운드 후 CEO 승인 필요
  • 자동 모드 — CEO "그만" 할 때까지 무한 진행
  • 참가자 자유 구성 — 추가/삭제/역할 변경
🏗️ 구현 전략
  • 기존 인프라 최대 활용 (채팅 SSE, LiteLLM)
  • CTO AI가 오케스트레이터 역할
  • 신규 서비스 1개 + API 엔드포인트 추가
  • DB 테이블 1개 추가

4 진행 모드 — 수동 / 자동

CEO가 토론 시작 시 진행 모드를 선택합니다. 토론 중간에 모드 전환도 가능합니다.

추천
🎛️
수동 모드 (승인제)
매 라운드가 끝나면 CEO 승인을 대기합니다.

라운드 완료 → CEO 확인 → 선택:
• "계속" → 다음 라운드 진행
• 방향 지시 → 지시 반영 후 진행
• "합성해" → 최종 기획서 생성
• "그만" → 토론 즉시 종료

라운드 수 제한 없음 — CEO가 그만 할 때까지.
🔄
자동 모드 (중단제)
CEO가 "그만"이라고 할 때까지 자동으로 라운드를 반복합니다.

라운드 완료 → 즉시 다음 라운드 시작
• CEO "그만" / "스톱" → 즉시 중단 + 합성
• CEO 방향 지시 → 실시간 반영 후 계속
• 예산 80% 도달 → 자동 일시정지 + CEO 확인

라운드 수 제한 없음 — CEO 중단 또는 예산 소진 시까지.

자동 모드 — CEO 실시간 개입 메커니즘

기존 interrupt_queue 활용: 자동 모드에서 CEO가 채팅 메시지를 보내면, 현재 진행 중인 참가자 발언이 끝난 직후 CEO 메시지가 interrupt_queue에 삽입되어 다음 참가자 컨텍스트에 즉시 반영됩니다.

중단 키워드 감지: "그만", "스톱", "stop", "중단", "종료" → 현재 라운드 완료 후 자동 합성으로 전환.
모드 전환 키워드: "수동으로", "승인제로" → 수동 모드로 즉시 전환.

5 토론 플로우

무제한 라운드 기반 진행. CEO가 그만 할 때까지 계속됩니다.

① CEO — 주제 + 참가자 + 모드 지정 공통

CEO가 토론 주제, 참가자 구성(모델 선택), 진행 모드를 지정합니다.
예: "과금 시스템 기획해줘. Opus, Gemini Pro, Sonnet 넣고 수동 모드로."
참가자/모드 미지정 시 → 기본 3인 프리셋 + 수동 모드로 제안 후 CEO 확인.

② 오케스트레이터 — 세션 초기화 공통

참가자 구성 확인 → 토론 세션 생성 → 각 참가자에 역할별 시스템 프롬프트 주입 → 라운드 1 시작.

③ 라운드 N — 참가자 순차 발언 공통

각 참가자가 순서대로 발언합니다. 라운드 2+에서는 이전 라운드 전체 발언을 컨텍스트로 참조합니다.
SSE 스트리밍으로 각 참가자 발언이 실시간 표시됩니다.

④-A 수동 모드 — CEO 승인 대기 수동

라운드 완료 후 오케스트레이터가 CEO에게 알립니다:

🔄 "계속" → 다음 라운드 💬 방향 지시 → 반영 후 진행 ✅ "합성해" → 최종 기획서 ⏹️ "그만" → 즉시 종료

라운드 수 제한 없음 — CEO가 원하는 만큼 반복.

④-B 자동 모드 — 연속 진행 자동

라운드 완료 즉시 다음 라운드가 시작됩니다. CEO가 메시지를 보내면 실시간 반영됩니다.
중단 키워드 ("그만", "스톱") → 현재 라운드 완료 후 자동 합성.
예산 80% 도달 → 자동 일시정지 후 CEO 확인 대기.

⑤ 합성 — 최종 기획서 생성 공통

전체 라운드의 논의를 종합하여 최종 기획서를 생성합니다.
합성 모델도 CEO가 지정 가능 (기본: 참가자 중 최고 성능 모델).
CEO 지시사항 반영 확인, 채택/미채택 근거, 실행 계획을 포함합니다.

class DiscussionMode(str, Enum):
    MANUAL = "manual"   # 매 라운드 후 CEO 승인 대기
    AUTO   = "auto"     # CEO "그만" 할 때까지 자동 진행

@dataclass
class ParticipantConfig:
    name: str           # "기획 A" — CEO 지정
    role: str           # "strategic_planner" — CEO 선택
    model: str          # "claude-opus-4-6" — CEO 직접 선택
    color: str          # UI 표시 색상 (자동 할당)
    avatar: str         # "A" (자동 할당)

class DiscussionOrchestrator:

    async def start_discussion(
        self,
        topic: str,
        session_id: str,
        participants: list[ParticipantConfig],  # CEO가 구성한 참가자
        mode: DiscussionMode = DiscussionMode.MANUAL,
        synthesizer_model: str | None = None,  # CEO 지정 합성 모델
        budget_usd: float = 10.0,
    ) -> AsyncGenerator[DiscussionEvent, None]:
        # max_rounds 없음 — CEO가 그만 할 때까지 무한
        ...

    async def run_round(self, discussion_id: str,
                        ceo_directive: str | None = None):
        # 수동: CEO 승인 후 호출 / 자동: 자동 호출
        for participant in self.participants:
            # 자동 모드: 매 참가자 발언 전 interrupt_queue 확인
            interrupt = await self._check_ceo_interrupt(discussion_id)
            if interrupt and interrupt.is_stop:
                break
            context = self._build_context(participant, ceo_directive, interrupt)
            async for event in self._call_participant(participant, context):
                yield event

        if self.mode == DiscussionMode.AUTO:
            if not self._should_stop():
                async for event in self.run_round(discussion_id):
                    yield event  # 자동: 즉시 다음 라운드
            else:
                async for event in self.synthesize(discussion_id):
                    yield event  # 중단 시 자동 합성
        else:
            yield DiscussionEvent("wait_ceo")  # 수동: CEO 대기

9 데이터 모델

CEO 모델 선택 + 수동/자동 모드를 반영한 스키마

CREATE TABLE discussion_sessions (
    id              UUID         PRIMARY KEY DEFAULT gen_random_uuid(),
    session_id      UUID         REFERENCES chat_sessions(id),
    topic           TEXT         NOT NULL,
    status          VARCHAR(20)  NOT NULL DEFAULT 'active',
                    -- 'active' | 'wait_ceo' | 'synthesizing' | 'done' | 'cancelled'

    -- v1.1: 진행 모드
    mode            VARCHAR(10)  NOT NULL DEFAULT 'manual',
                    -- 'manual' (승인제) | 'auto' (중단제)

    -- CEO가 직접 구성한 참가자 (모델 포함)
    participants    JSONB        NOT NULL,
                    -- [{name, role, model, color, avatar}]  ← CEO 선택 모델

    -- v1.1: 라운드 제한 없음 (CEO 중단 시까지)
    current_round   INT          DEFAULT 0,
    rounds          JSONB        DEFAULT '[]',
                    -- [{round, ceo_directive, mode_at_round,
                    --   responses: [{participant, content, model, cost, tokens}]}]

    -- 합성
    synthesizer_model VARCHAR(50),  -- CEO 지정 합성 모델
    synthesis       TEXT,
    artifact_id     UUID         REFERENCES chat_artifacts(id),

    -- 비용/시간
    budget_usd      DECIMAL(10,4) DEFAULT 10.0,
    total_cost      DECIMAL(10,4) DEFAULT 0,
    duration_ms     INT,

    created_at      TIMESTAMPTZ  DEFAULT now(),
    updated_at      TIMESTAMPTZ  DEFAULT now()
);
