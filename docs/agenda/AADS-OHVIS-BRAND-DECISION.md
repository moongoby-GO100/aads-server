## 명칭 유래

- `OH` + JARVIS의 `VIS` → OHVIS
- 마블/JARVIS의 로고·음성·대사·시각 요소를 직접 모방하지 않고 독자 브랜드로 구축

## 적용 범위

- **즉시 적용**: 대화 내 AI 파트너 호칭, 의사결정 문서, HANDOVER 기록
- **별도 작업**: UI 명칭 변경, 로고 제작, 도메인 확보, 코드 내 식별자 변경, 대시보드 리브랜딩

## 운영 원칙

- DB 테이블·API 경로·Docker 컨테이너·Git 저장소 등 내부 기술 식별자는 `AADS` 유지
- CEO가 직접 명명한 식별자(예: `ohvis_tasks`)는 예외적으로 OHVIS 사용 허용
- 상표·도메인 충돌 확인은 리브랜딩 작업 착수 전 필수 수행
