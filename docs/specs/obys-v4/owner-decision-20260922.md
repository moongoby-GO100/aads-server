# obys-v4 슬라이스 소유권 결정표 — CEO 승인 상정 (2026-09-22)

## 0. 건수 정정 (R-CRITICAL)

원 지시는 "converge 미충족 24건(충돌 12·미정 12)"이었으나, 실측 결과 **고유 슬라이스는 12건**(충돌 6 + 미정 6)이다.
`roadmap.md`에서 `충돌 —`/`미정 —` 문자열이 표(6+6=12줄)와 하단 "충돌/점검 필요 슬라이스" 목록(같은 12건 재나열)에 **두 번씩** 등장해 `grep -c` 매칭이 24가 되는 것을 확인했다 [명령 확인: `grep -c "충돌 —"/"미정 —" roadmap.md` → 각 12, 표 행 33개 중 충돌 6·미정 6·확정 21].
아래 표는 실제 고유 슬라이스 12건 전체를 다룬다. 24라는 표현은 이번 결정표 이후 폐기를 권고한다.

## 1. 근거 원칙 — PRD 6절

`docs/PRD-OBYS-MOCKUP-V3-DETAIL-PAGES.md` 6절(줄 55-70)은 소유 메뉴 6개(매출관리/계좌·입출금/재고·매입/세무·회계/외부연동/문서보관함)와 규칙을 명시한다:
- **외부연동(연동 관리)은 인증·수집주기·권한·오류복구만 소유**하고, 실제 거래조회·등록 화면은 각 업무 메뉴가 소유한다(연동 화면을 거래화면과 중복 제공하지 않는다).
- **문서보관함(경영자료·보관)의 "증빙"은 "증빙 원본보관"**으로 명시해 세무·회계의 증빙대장과 분리한다.

PRD 6절이 다루지 않는 6개 메뉴(통합 홈/할 일·알림/권한·감사로그/사업자·지점/알림센터/통합 승인함)가 걸린 슬라이스는 PRD에 문구가 없으므로 아래 권고에 **[PRD 미기재 — 권고]** 태그를 붙였다. 나머지는 PRD 문구를 직접 근거로 삼아 **[PRD 6절 근거]** 태그를 붙였다.
