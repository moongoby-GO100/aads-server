## 3. 승인 전에 알아둘 점

- **결정표와의 차이.** 결정표는 원가·마진 시뮬레이션을 `[PRD 6절 근거 + 구조적 제약]` 으로 적었으나, PRD 6절에 원가·마진 행은 없다. 그 부분의 근거 표기는 과하다. 이 문서는 시뮬레이션을 근거 없음으로 분류했다.
- **연동 3건의 이중성.** bank-connect, supplier-connect, sales-channel-connect 는 '자동연동'(설정) 레이블과 '자료 등록·현황'(거래) 레이블이 한 슬라이스에 섞여 있다. 1순위는 불릿의 "거래 조회·등록을 중복 제공하지 않는다" 를 따라 업무 메뉴로 잡았지만, 설정 화면 자체는 6절 표상 외부연동 몫이다. CEO 가 "설정 화면과 거래 화면을 분리" 하기를 원하면 이 3건도 분리 대상이 된다.
- **라벨 문제.** 게이트가 인정하는 상태는 정확히 `정본 확정(PRD 6절 소유 메뉴와 일치)` 하나뿐이다(`app/services/pipeline_runner_service.py` 의 `_OWNER_RESOLVED_STATUS`). PRD 6절에 없는 소유(미정 6건)를 이 라벨로 올리면 "PRD 6절과 일치" 가 사실과 다르다. PRD 6절에 행을 추가해 사실로 만들 것인지, 별도 상태를 인정하도록 게이트를 바꿀 것인지 CEO 가 정해야 한다.

## 4. 승인 요청

### A. 12건 일괄 승인

- 승인 범위: 충돌 6건의 후보·분리안 + 미정 6건의 소유 메뉴(CEO 가 표의 각 행에 직접 지정 — 이 문서는 근거가 없어 후보를 주지 않았다).
- 함께 결정할 것: 분리 대상 3건(receipt-upload, tax-return-preview, order-detail)의 신규 slug 발급, order-detail 시뮬레이션의 소유 메뉴, 3절의 라벨 문제.

### B. 근거 있는 것만 부분 승인 (권장)

- B-1: 단일 소유 후보가 PRD 6절 불릿·표 행에 근거한 3건 — bank-connect, supplier-connect, sales-channel-connect. sales-channel-connect 는 불릿 + 7절 해석에 근거한다는 점을 확인하고 승인한다.
- B-2(선택): 분리안 3건 — receipt-upload, tax-return-preview, order-detail 의 분리 방향만 승인. order-detail 의 시뮬레이션 몫은 제외.
- 보류: 미정 6건과 order-detail 시뮬레이션은 근거가 없으므로 CEO 가 소유 메뉴를 직접 지정하기 전까지 보류한다.

### 승인하면 실제로 실행되는 것

승인은 결정일 뿐 그 자체로 아무 파일도 바꾸지 않는다. 별건 지시서로 다음이 실행된다.

1. 로드맵 상태열은 손으로 고치지 않고 생성기 `scripts/gen_obys_specs.py` 를 통해서만 바뀐다. 현재 생성기는 메뉴 참조 개수만으로 상태를 파생하고 CEO 승인 결과를 입력받는 경로가 없다(2026-09-29 확인). 그래서 승인된 소유권을 받는 입력을 생성기에 추가하는 변경이 먼저 필요하다.
2. 생성기를 재실행하면 roadmap.md 상태열과 각 슬라이스의 spec/plan/tasks 가 함께 다시 쓰인다. 충돌 표시(⚠️)가 남아 있으면 analyze 게이트도 지시서를 막으므로 이 재생성이 필요하다.
3. 분리 대상은 신규 slug 를 발급해 `docs/specs/obys-v4/<신규slug>/{spec,plan,tasks}.md` 를 만든다.
4. 대장(`goal_documents`) 등록은 그 뒤 별건이다.

### 되돌리는 방법

로드맵은 생성 산출물이므로 손으로 되돌리지 않는다. 위 별건에서 생성기에 넣은 승인 입력을 제거(커밋 revert)하고 `python3 scripts/gen_obys_specs.py` 를 다시 실행하면 파생 규칙대로 충돌/미정 상태가 복원될 것으로 예상한다(후속 작업에서 실제 실행해 확인할 것, 이 문서 작성 시점에는 실행하지 않았다).

### 승인하지 않으면

해당 슬라이스는 로드맵 상태가 충돌 또는 미정으로 남아 구현 지시서 제출이 계속 HTTP 409 로 막힌다. 부분 승인이면 승인된 슬라이스만 통과하고 나머지는 계속 막힌다.
