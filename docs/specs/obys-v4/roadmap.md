# 오비서 V4 기획 로드맵 — Spec of Specs


PRD 원본: `docs/PRD-OBYS-MOCKUP-V3-DETAIL-PAGES.md`. 소스 실측: `app/static/apps/obys/mockup-v3.html`의 `submenuItems`(14개 상위 메뉴 · 61개 하위 항목 · 고유 상세화면 33개).

CEO 지시는 "35개 메뉴"였으나 실측 결과 고유 상세화면은 **33개**다. 추측으로 2개를 채우지 않고 실측값을 그대로 쓴다(R-CRITICAL). 하위 항목 총량(61개) 기준으로는 35에 더 가깝게 보일 수 있어 차이를 여기 명시한다.

각 슬라이스는 `docs/specs/obys-v4/<slug>/{spec,plan,tasks}.md` 3산출물로 고정된다. 추가지시는 이 3파일을 갱신하는 형태로만 반영하고, 대화에만 흩어져 남기지 않는다.
