## 2. 서버 계약 (aads-server)

### 2-1. 응답 필드 추가 — `GET /goals/for-session/{session_id}`

`goals[]` 각 항목에 아래를 **추가**한다. 기존 필드(`strip_rank` 포함)는 이름·값·의미를 바꾸지 않는다.

| 필드 | 타입 | 값 |
|---|---|---|
| `strip_group` | string | `working` \| `awaiting` \| `blocked` \| `p0` \| `other` \| `paused` \| `dormant` |
| `strip_order` | int | 위 그룹의 표시 순번 0~6 (`working`0 `awaiting`1 `blocked`2 `p0`3 `other`4 `paused`5 `dormant`6) |
| `last_activity_at` | string(ISO8601) \| null | `goal_signals` 파생 신호의 마지막 활동 시각. 없으면 null |

`goals[]` 정렬 키는 `(strip_order, priority_rank, -last_activity_epoch(없으면 맨 뒤), title)` 로 바꾼다. 화면 구버전은 자기 `strip_rank` 로 다시 정렬하므로 정렬 변경은 구버전에 영향이 없다.

### 2-2. 분류 함수 — `app/services/goal_activity.py`

```python
STRIP_GROUP_ORDER = ("working", "awaiting", "blocked", "p0", "other", "paused", "dormant")

def strip_group(activity, priority, dormant, *, paused, status, dispatch_note) -> str:
    if paused:                                   return "paused"
    if activity == ACTIVITY_WORKING:             return "working"
    if activity == ACTIVITY_AWAITING:            return "awaiting"
    if dormant or status == "draft":             return "dormant"
    if status == "blocked" or (dispatch_note or "").strip(): return "blocked"
    return "p0" if is_p0(priority) else "other"

def strip_order(group: str) -> int: STRIP_GROUP_ORDER.index(group)

def dropdown_sort_key(item) -> tuple:  # (strip_order, priority_rank, -epoch|inf, title)
```

- 기존 `strip_rank()`·`strip_sort_key()`·`sort_for_strip()` 는 남긴다(다른 호출자·테스트 보호). `goals_for_session` 만 새 키로 정렬한다.
- `last_activity_at` 은 `signals_for_rows()` 결과에 이미 있으면 그대로 쓰고, 없으면 `goal_signals` 의 마지막 활동 조회 함수(`last_activity_at` 반환, 같은 파일 307행 근처)를 재사용한다. 새 쿼리를 추가하지 않는 쪽을 우선한다.

### 2-3. 서버 테스트

- `strip_group` 7개 분기 각각, 그리고 우선순위 충돌(멈춤+작업중 → paused, 휴면+막힘 → dormant, 초안 → dormant).
- `dropdown_sort_key`: 같은 그룹 안 P0-CRITICAL < P0 < P1, 같은 우선순위에서 최근 활동이 먼저, 활동 없음은 뒤.
- `goals_for_session` 응답에 세 필드가 있고 기존 `strip_rank` 값이 변하지 않음.
- 실행: `bash scripts/run_unit_tests.sh <테스트 파일>` 종료코드 0.

## 3. 화면 (aads-dashboard)

### 3-1. 순수 함수 — `src/lib/goalStrip.ts`

| 함수 | 역할 |
|---|---|
| `DROPDOWN_GROUP_ORDER`, `DROPDOWN_GROUP_LABEL` | 7그룹 순서와 이름(`🔄 작업중` `⏳ 대표님 대기` `⛔ 막힘` `P0` `P1 · P2` `⏸ 멈춤` `💤 휴면·초안`) |
| `dropdownGroupOf(g)` | 서버 `strip_group` 이 7개 중 하나면 그대로, 아니면 §2-2 와 같은 규칙으로 판정(`goal_paused`, `activity`, `dormant`, `status`, `dispatch_note`, `priority`) |
| `sortDropdownGoals(goals)` | 서버 `strip_order` 가 있으면 그것, 없으면 그룹 순번 → `priority_rank` → `last_activity_at` 최근순 → 제목 |
| `groupDropdownGoals(goals)` | 빈 그룹을 뺀 `{key,label,goals}[]` |
| `dropdownTriggerSummary(goals)` | `{ total, working, awaiting, blocked, top }` (top = 정렬 1순위) |
| `freezeOrder(prevIds, goals)` | 열린 동안 순서 고정: 이전 id 순서를 유지하고, 새 목표는 자기 그룹의 끝에, 사라진 목표는 제외 |
| `progressPct(progress)` | 0~1 이면 ×100, 그 외 그대로, 0~100 으로 자르고 반올림 (기존 칩 계산과 동일) |

기존 `groupStripGoals`·`sortStripGoals`·`stripRankOf` 등은 다른 곳(`DormancyCard` 등)에서 쓰면 남기고, 아무도 쓰지 않으면 지운다. `StripGoal` 타입에 `strip_group?`, `strip_order?`, `goal_paused_reason?`, `last_activity_at?` 를 추가한다.

### 3-2. 컴포넌트 — `src/components/chat/GoalStrip.tsx`

- `GoalStripProps` 는 바꾸지 않는다(`open`/`onOpenChange` 를 드롭다운 열림으로 쓴다). `page.tsx` 수정은 필요할 때만 최소로.
- 제거: `VISIBLE_CHIPS`, 가로 칩 줄, `목표 +N`, `접기`.
- 버튼: 높이 32px(모바일 36px), `🎯 목표 N` + 조치 필요 개수 칩(🔄n ⏳n ⛔n, 0 생략) + 구분선 + 1순위 목표(아이콘·배지·제목·4px 진행률 막대·%) + `▾/▴`. `aria-haspopup="listbox"`, `aria-expanded`, `aria-controls`.
- 데스크톱 팝오버: 버튼 아래 `position:absolute`, 폭 440px, 최대 높이 `min(60vh, 520px)`, 세로 스크롤, 그림자. 대화 영역 높이는 바뀌지 않는다(겹쳐 뜬다).
- 모바일 하단 시트: `position:fixed` 스크림 + 시트, 최대 70vh, 줄 높이 ≥ 44px, 머리 오른쪽 ✕.
- 줄: 본문 버튼(`role="option"`, `aria-selected = panelGoalId === goal_id`) + 오른쪽 자동승인 칩 버튼(기존 `AutoApprovalPill`·상세 시트 그대로). 둘째 줄은 데스크톱만, 모바일은 막힘·멈춤 사유만 둘째 줄.
- 닫기: Esc, 바깥 `pointerdown`, 버튼 재클릭, 스크림, ✕. 닫을 때 버튼으로 포커스 복귀.
- 키보드: 열리면 첫 줄(또는 선택된 줄)에 포커스, ↑↓ 로 줄 이동, Enter/Space 선택, Home/End.
- 순서 고정: 열릴 때 `sortDropdownGoals` 결과의 id 목록을 저장하고, 열린 동안 `freezeOrder` 로 그린다.
- 상태: 신호 실패 → 버튼 옆 ⚠️ 칩 유지 + 목록 하단 `다시 시도`(기존 `onToggleCard` → 카드의 재시도 경로 그대로). 목표 0건 → 버튼 문구 `🎯 목표 0` 과 목록 안내 문구(PRD §4). 전체 정지 → 기존 빨간 배지 유지.
- 색·글꼴: 기존 CSS 변수(`--ct-bg` `--ct-card` `--ct-border` `--ct-text` `--ct-text2`)와 기존 배지 색을 그대로 쓴다. 새 색은 그룹 머리 아이콘 외에 추가하지 않는다.
