# 현재 정본과 서버 원장 조회 안내

작성: 2026-10-01. 이 문서는 조회 경로와 근거 구분을 설명한다. 서버 건강·부하·활성 배포는 요청 시 재조회한다.

## 1. 현재 서버 구성

화면: https://aads.newtalk.kr/ops/servers

API: `/api/v1/ops/status`. 구성 정본: `app/services/server_registry.py`의 `list_ledger_servers()` / `LEDGER_SERVER_IDS`. 총 원장 4개와 건강 감시 목록 3개는 별개다. `CANONICAL_SERVER_IDS`는 현재 건강 감시 대상이며 총 서버 수로 해석하지 않는다.

아래 구성은 2026-10-01 14:25:12 KST API 대조 기준이다. 향후 이 표보다 현재 API 구성을 우선한다.

| 표시명 | 서버 키 | 주소 | 프로젝트 | 건강 감시 |
|---|---|---|---|---|
| 콘타보116 | `contabo116` | `5.104.86.116` | AADS | 포함 |
| 카페24-114 | `cafe24_114` | `114.207.244.86`, SSH 7916 | SF, NTV2, NAS | 포함 |

| 콘타보14 | `contabo14` | `5.104.86.14` | GO100, KIS | 포함 |

감시 미포함 서버의 `unknown`은 장애 판정이 아니다. 구성 등록 조회시각과 CPU·메모리·건강 실측시각도 별개다. SSH 접근 실패를 서버 자원 고갈이나 서버 중단이라고 확정하지 않는다.

과거 `server68`, `server211`, `116.120.58.155` 주소는 당시 자료의 이력이다. 실제 대상은 현재 원장과 SSH 등록 경로로 확인한다. 러너 노드가 세 곳이라는 사실도 원장 서버 수를 세 곳으로 줄이지 않는다.

## 2. 문서 정본

프로젝트 문서 API: `/api/v1/projects/{project_key}/documents`.

- 승인 기준은 같은 문서 키의 `approved_revision_id`이다. `approved_only=true`로 조회하고 `authoritative`, revision, version, content hash를 확인한다.
- 기본 GET은 최신 초안·검토본도 반환할 수 있다. 최근 작성일이나 최신 버전 번호만으로 승인 정본을 판단하지 않는다.
- 승인본이 없거나 권한·조회가 실패하면 그 상태를 표시한다. 검색된 과거 파일을 자동으로 정본으로 삼지 않는다.
- 현재 미션의 사용자 지시·구현 권한과 문서 API 승인 상태·코드 운영 반영 상태는 각각 기록한다.

## 3. 운영 사실 확인

현재 릴리스 SHA, 실제 프로세스 경로, 실제 ControlGroup, 수집 마지막 저장시각, 최신 완성 봉, 계산 cursor, 발행·전략 수신·주문 영수증은 각각 조회한다. 문서의 설정값과 실제 실행값이 다르면 둘을 분리해 보고한다.

GO100 인프라 책임 세션: https://aads.newtalk.kr/chat#3ad8d4c5-10f6-49c2-bdab-3bc1f48d05ec

최신 인프라 인계 키 `go100-resource-p0a-p0b-execution-20261001`과 후속 조치 기록을 먼저 확인한다. 2026-06-19 서버 이전 기록·2026-06-23 3서버 토폴로지를 현재 운영 상태의 근거로 사용하지 않는다. 예약 작업은 실제 실행 결과와 구별한다.

## 4. 검색 자료를 사용할 때

자료마다 프로젝트·문서 키·승인 상태·버전·해시·출처를 확인한다. 파일 변경시각·색인시각·작성일·운영 검증시각을 바꾸어 표현하지 않는다. 과거 문서는 당시 사실의 근거로 보존하고 현재 후속 문서와 연결한다. 목록의 `현행` 표시는 고정된 보증이 아니므로 현재 코드·승인 포인터·운영 원장을 대조한다.

## 5. 공통 경로 개선

PRD: [AADS 현재 정본·운영 근거 제공 v1.0.0](../plans/AADS-CURRENT-AUTHORITY-CONTEXT-PRD-v1.0.0-20261001.md).

프로젝트 문서 키: `aads-current-authority-context` (AADS). 등록 시점 API 상태는 `draft`; 담당 검토·승인 및 코드 배포 완료는 별도 확인한다. 공통 문맥 원장 통합, 검색 메타데이터 보존, 과거 자료 표시는 구현 지시된 상태다. 이 문서를 저장한 것만으로 모든 세션의 문맥이 교정됐다고 보고하지 않는다.
