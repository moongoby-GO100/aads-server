종합차트는 차트가 주인공이고, 정보와 지표는 접히는 레이어로 붙어야 합니다.

현재 종목차트는 분봉과 지표 경로는 있으나, 컨트롤과 부가 정보가 차트 주변에 노출되어 가격 캔들의 기본 판독을 방해합니다. V4는 전체화면 가격 차트를 기본값으로 두고, 기술지표 선택 화면은 접힌 상태에서 필요할 때만 열리게 설계합니다.

기본: 전체화면 차트 레이어 패널: 기본 접힘 분봉: 1/3/5/10/15/30/60분 MA: 3/5/10/20/60/120/240 + 사용자 설정

결론

표시 우선순위

가격 캔들, 거래대금, 핵심 MA 3개를 기본으로 노출하고 나머지는 접힌 레이어에서 켭니다.

동시 MA 권장

기본 3개, 최대 5개를 권장합니다. 6개 이상은 경고 후 허용하되 색상/두께 자동 약화가 필요합니다.

지표 위치

가격 위 오버레이, 가격 아래 패널, 하단 도크 사이를 레이어별로 이동할 수 있어야 합니다.

정보 패널

수급, 호가, 뉴스, AI 시그널은 우측/하단/상단 보조 패널로 접고 펼치는 구조가 맞습니다.

3. 모바일 목업

모바일 원칙

모바일은 차트 높이를 먼저 확보해야 하므로, 지표 선택은 하단 sheet로 열고 기본은 닫습니다. 시간봉 버튼은 가로 스크롤 칩으로 두며, 사이드 정보는 하단 접이식 카드로만 노출합니다.

터치 우선

지표 칩, 분봉 버튼, 전체화면 버튼은 최소 36px 높이를 확보합니다.

4. 기술지표 레이어 상세 설계

그룹기본/확장권장 위치시각화 규칙
이동평균선 기본 프리셋: 3, 5, 10, 20, 60, 120, 240. 사용자 숫자 입력 추가. 가격 위 동시 기본 3개, 권장 최대 5개. 6개 이상은 색상 채도를 낮추고 범례를 접습니다.
거래대금/거래량 거래대금 기본, 거래량 토글 전환. 가격 아래 첫 패널 거래대금은 억원 단위, 거래량은 주 단위. 전일 대비 색상과 상승/하락 색상을 분리합니다.
추세 VWAP, Bollinger, Ichimoku, Supertrend. 가격 위 또는 아래 Bollinger/Ichimoku는 면적 표현이므로 캔들 대비 opacity 8~14%로 제한합니다.
모멘텀 RSI, MACD, Stochastic, CCI. 가격 아래/하단 가격 패널과 분리합니다. 기준선 30/50/70 또는 0선을 항상 표시합니다.
거래/수급 OBV, MFI, 체결강도, 외국인/기관 순매수. 하단 또는 접힌 도크 투자 판단용 정보는 가격 캔들을 가리지 않도록 하단 카드나 보조 패널에 둡니다.
AI/전략 레이어 매수/매도 시그널, 백테스트 체결, 지지/저항, 눌림/돌파 구간. 가격 위 + 하단 요약 마커는 B/S 단문, 상세 사유는 hover 또는 하단 요약 카드로 분리합니다.

MA 동시 노출 기준

기본값: 3개

MA3, MA5, MA20 또는 사용자 프리셋 3개를 기본으로 둡니다.

권장 최대: 5개

단기 2개, 중기 2개, 장기 1개가 캔들 판독을 크게 해치지 않는 한계입니다.

허용 최대: 7개

3/5/10/20/60/120/240 전체를 켤 수는 있으나, 경고와 자동 약화가 필요합니다.

색상 규칙

단기 warm, 중기 cool, 장기 neutral 계열로 묶어 구분합니다.

성능 규칙

분봉 1,000개 이상에서는 켜진 레이어 수를 제한하거나 가상화/샘플링을 적용합니다.

5. 구현 항목

단계작업상세검증
P0 전체화면 차트 레이아웃 `/stock/[code]`의 `max-w-7xl + aside` 구조를 차트 중심 full-bleed 구조로 재배치합니다. aside는 접힘 패널로 전환합니다. PC 1440/1920, 모바일 390 viewport에서 차트가 첫 화면 대부분을 차지하는지 확인
P0 기술지표 drawer 기본 접힘 현재 펼쳐진 지표 버튼 영역을 `LayerControlDrawer`로 분리하고 기본 collapsed 상태로 시작합니다. 초기 진입 시 설정 패널이 차트를 가리지 않는지 확인
P0 MA 설정 확장 `IndicatorKey`를 고정 enum에서 period 기반 설정으로 바꾸고 3/5/10/20/60/120/240 + custom period를 지원합니다. MA3/10/240 계산값과 기존 MA5/20/60/120 회귀 확인
P0 분봉 버튼 완성 현재 코드상 1/3/5/10/15/30/60분봉은 존재합니다. UI에서 동일 폭 버튼과 URL query 동기화를 정리합니다. `tf=1m/3m/5m/10m/15m/30m/60m` 직접 진입 확인
P1 거래대금 기본 패널 현재 API 타입에는 `volume`만 있으므로 `close * volume` 프론트 계산으로 시작하거나 백엔드에 `trading_value`를 추가합니다. 억원 단위 표시, 거래량 토글 전환, 결측 데이터 처리 확인
P1 레이어 위치 이동 `position: overlay | upper | lower | dock` 모델을 추가하고 드래그 정렬 또는 위/아래 버튼으로 순서를 저장합니다. RSI/MACD/OBV가 위·아래 이동 후 차트 축과 겹치지 않는지 확인
P2 프리셋 저장 사용자별 차트 프리셋을 저장합니다. 기본형, 단타형, 추세형, 수급형을 제공하면 반복 사용성이 좋아집니다. 저장/불러오기/초기화, 다른 사용자 접근 차단 확인
