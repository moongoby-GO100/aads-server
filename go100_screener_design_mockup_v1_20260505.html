1. 현재 문제

조건, 결과, 차트, 저장 조건이 같은 위계로 나열되어 핵심 행동이 흐립니다. 검색 전후 상태가 구분되지 않고 표와 차트가 서로 떨어져 종목 판단 흐름이 끊깁니다.

2. 개선 방향

좌측 조건 패널, 중앙 결과 테이블, 우측 종목 근거 패널로 고정합니다. 사용자는 조건을 바꾸고, 결과를 고르고, 차트와 근거를 즉시 확인합니다.

3. 추가 기능

컬럼 프리셋, 관심/제외 토글, 조건 버전 저장, 전략카드 결과 탭, 위험 플래그, 모바일 하단 실행바를 추가해 반복 사용성을 높입니다.

4. 개발 적용 순서

P0는 레이아웃 재구성, P1은 표 컬럼/우측 패널/차트 연동, P2는 저장 조건 서버화와 개인화입니다. 기존 API는 유지하고 화면 구조부터 바꿉니다.
