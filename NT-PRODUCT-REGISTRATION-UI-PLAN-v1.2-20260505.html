NTV2 상품등록 UI 수정기획 v1.2
요약 흐름도 역할 의존성 V1 필드 DB V2 비교 다음 작업

상품등록은 단순 도매 등록폼이 아니라 운영, 촬영, 판매, 정산이 연결된 업무 허브다

V1 검수 결과 상품등록/수정은 goods, goods_detail, goods_image, goods_master, goods_option_code에 분산 저장되며, 화면 입력 필드는 상품 기본정보, 도매/매입처, 촬영/모델, 가격/채널, 상세페이지, 이미지, 재고/배송/세금, 마켓 전송까지 포괄한다.

V2 현 구조는 기본 상품 CRUD 수준이므로 V1 운영을 그대로 대체하려면 상품등록 화면을 역할별 워크플로우와 상태 기반 입력 단계로 재설계해야 한다.

상품등록 흐름도

1. 등록 출처 결정도매 직접등록, 뉴톡 관리자 대행, 촬영서비스 연계, 뉴톡 직접판매 중 하나로 시작한다.
2. 샘플/입고 접수샘플 입고일, 촬영 필요 여부, 매입처, 담당자를 확정한다.
3. 기본 상품 생성카테고리, 상품코드, 브랜드, 매입처, 상품명, 색상/사이즈를 생성한다.
4. 촬영/콘텐츠 작업모델, 촬영일, 사진, NAS, 웹작업자, 상세설명을 연결한다.
5. 가격/판매조건원가, 판매가, 채널별 판매가, 재고, 배송비, 세금, 노출 상태를 입력한다.
6. 검수/마켓 준비이미지, 상세페이지, 키워드, 옵션코드, 채널별 상품명을 검수한다.
7. 노출/판매/정산자사몰/뉴톡/입점몰/도매 채널 노출 후 발주, 위탁배송, 정산으로 연결한다.
